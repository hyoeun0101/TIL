## 🍎 해쉬 테이블

- 키와 데이터로 이루어진 자료 구조
- 해쉬 함수에 키 값을 주면, 데이터가 저장된 인덱스를 반환한다.

### 해쉬 함수?

- 데이터 값을 일정 범위의 값으로만 반환하는 함수

### 슬롯(Slot)?

- 해쉬 테이블에서 하나의 데이터를 저장할 수 있는 공간

### 장점

- 데이터 저장/읽기 속도가 빠르다.(검색 속도가 빠르다)
- 키에 대한 데이터가 있는지 중복 확인이 쉽다.

### 단점

- 키가 중복될 경우 값의 충돌이 발생할 수 있으며, 이를 위한 별도의 자료구조가 필요하다.

### 주요 용도

- 검색이 많이 필요한 경우
- 저장, 삭제, 읽기가 빈번히 발생하는 경우
- 캐시 구현 : 중복 확인이 쉽기 때문
