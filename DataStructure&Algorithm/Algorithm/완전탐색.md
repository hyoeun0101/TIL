## 🍎 완전탐색
- 문제를 해결하기 위해 확인해야 하는 모든 경우의 수를 탐색하는 방법
- 그 중에서 백 트래킹(Back-Tracking)을 통해야 하는 상황을 해결하기!
- 모든 코테 문제에서 기본적으로 접근해봐야 한다. 많은 연습이 필요함

- 부분 점수 얻기 좋은
- 전부 탐색하기에 시간 복잡도가 높다.

## 코테에 나오는 완전 탐색 4가지 종류
N개 중  - 중복 허용     
        - 중복 X     
M개를 - 순서있게 나열    
     - 고르기     

```java
//M개 전부 고름 : 조건에 맞는 탐색 한가지를 성공한 것
//아직 M개를 고르지 않음 : k번째부터 M번째 원소를 조건에 맞게 고르는 모든 방법을 시도
static void rec_fun(int k) {}

public static void main(String[] args) {
    input();
    // 1(k)번째 원소부터 M번째 원소를 조건에 맞게 고르든 모든 방법을 탐색
    rec_func(1);
}
```
- N개 중 중복을 허용해서, M개를 순서 있게 나열하기
    - 시: O(N^M)  공: O()
