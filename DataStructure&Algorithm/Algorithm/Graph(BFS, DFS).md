- 그래프 = 정점(Vertex) + 간선(Edge)
- 간선 : 무방향(양방향), 벙향 + 가중치

- 정점의 degree(차수) : 정점에 연결된 간선의 수
- 모든 정점의 차수의 합 = 간선의 수 \* 2

### 그래프 저장하는 대표적인 두 가지 방법

- 인접 행렬 (Adjacency Matrix)
  - O(V^2) 공간 필요 : 2차 배열이 필요하다.
  - A에서 B로 이동 가능? 가중치 얼마?
    - O(1) : 인덱스로 바로 찾을 수 있음.
  - 정점 A에서 갈 수 있는 정점은?
    - O(V) : A의 행 안에서 배열 돌면서 모든 원소 확인.

```java
int[][] adj = int new[V][V]
```

- 인접 리스트 (Adjacency List)
  - O(E) 공간 필요 : E는 간선의 수\*2
  - A에서 B로 이동 가능? 가중치 얼마?
    - O(min(deg(A), deg(B))) : 양방향이라면 A의 차수, B의 차수 중 최솟값 선택, 방행성이라면 O(deg(A))
  - 정점 A에서 갈 수 있는 정점은?
    - O(deg(A)) : A의 차수

```java
ArrayList<ArrayList<Integer>> obj;
```

### 정리

|                                  | 인접행렬 | 인접리스트             |
| -------------------------------- | -------- | ---------------------- | --- | --------- |
| A와 B를 잇는 간선 존재 여부 확인 | O(1)     | O(min(deg(A), deg(B))) |
| A와 연결된 모든 정점 확인        | O(       | V                      | )   | O(deg(A)) |
| 공간 복잡도                      | O(V)     | O(E)                   |

- 간선 존재 여부를 찾는 문제라면 인접 행렬을, 모든 정점을 확인하는 문제라면 인접리스트를 활용할 수 있다. 하지만 공간 복잡도를 고려한다면 첫 번째 경우라도 인접 리스트를 써야한다.

### 그래프 문제 푸는 법

1. 정점과 간선의 정확한 정의를 파악하라.

- 이 문제에서는 이게 정점을 의미하고 저게 간선을 의미하는구나.

2. 인접 리스트를 쓸지, 인접 행렬을 쓸지 결정해야 한다. 거의 인접 리스트 사용.
