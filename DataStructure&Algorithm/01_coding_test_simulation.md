백준 - 14503 로봇청소기

### 조건
- N,M 3~50 
- d : 0,1,2,3
- 4칸 먼저 탐색 -> 빈 칸 있으면 반시계 방향 90도 회전 후 이동 -> 다시 4칸 탐색
- 4칸 먼저 탐색 -> 빈 칸 없으면 뒤로 후진

- 최대 칸수 : 50 * 50
- 시간복잡도 : O(NM)

### 자료구조
- int[][]
- 현재 위치 (r,c)
- 현재 방향 d
- 청소 완료 표시
  - 0 : 빈칸
  - 1 : 벽
  - 2 : 청소 완료

### 구현
- 앞 칸이 0이면 이동, 0이 아니면 회전. 이를 4번 반복. 4번 다 실패하면 후진
