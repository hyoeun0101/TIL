❗ 커밋이 하나도 없으면 브랜치 생성이 안된다 ❗
__
### 브랜치 생성
```
git brach test
```
### 브랜치 생성 동시에 이동
```
git switch -c test
```
### 브랜치 삭제
```
git branch -d test
```
### 브랜치 이름 변경
```
git branch -m "기존 브랜치명" "새 브랜치명"
```
### 여러 브랜치 내역 한꺼번에 보기
```
git log --all -decorate --oneline --graph
```
- git log는 현재 브랜치의 커밋 내역만 보여줌
### 브랜치 보기
```
git branch -a
```
: 원격, 로컬 브랜치 모두 보여줌

## 원격 저장소에 있는 브랜치 로컬로 받아오기
```
git fetch
git switch -t origin/branchname
```
- -t : 원격 브랜치와 같은 이름의 로컬 브랜치 생성하고 switch 한다.
### 원격 브랜치 삭제
```
git push origin -d branchname
```
