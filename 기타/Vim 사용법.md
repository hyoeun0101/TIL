| 작업                | vi 명령어 | 상세                                         |
| ------------------- | --------- | -------------------------------------------- |
| 입력 시작           | i         | 명령어 입력 모드에서 텍스트 입력 모드로 전환 |
| 입력 종료           | esc       | 텍스트 입력 모드에서 명령어 입력 모드로 전환 |
| 저장 없이 종료      | :q        |                                              |
| 저장 없이 강제 종료 | :q!       | 입력한 것이 있을 때 사용                     |
| 저장하고 종료       | :wq       | 입력한 것이 있을 때 사용                     |
| 위로 스크롤         | k         |                                              |
| 아래로 스크롤       | j         |                                              |
