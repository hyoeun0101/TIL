## 🍎 HTTP란?

- HyperText Transfer Protocol
- 인터넷 상에서 클라이언트와 서버가 자원을 주고 받을 때 쓰는 통신 규약.
- 모든 것이 HTTP이다. HTTP 메시지에 모든 것을 전송한다.
  - 모든 형태의 데이터를 전송한다.
  - HTML, Text, Image, 음성, 영상, 파일, JSON, XML 등
- 서버 간에 데이터를 주고 받을 때도 대부분 HTTP를 사용한다.
- `HTTP 1.1`을 가장 많이 사용한다.

  - 2,3도 점점 증가하고 있는 추세이다. 1,2는 TCP 기반으로 개발이 되었고, 3은 UDP 기반으로 개발이 되었다.
  - UDP가 속도는 빠른데 신뢰성은 떨어진다. 이런 문제는 애플리케이션 계층에서 흐름제어, 혼합제어를 구현하여 부족한 신뢰성을 보안하고 있다.

- 과거 RFC2616
  - General, Request, Response, `Entity`로 구성되어있다.
- 현재 RFC723X
  - `표현 데이터`로 이루어져 있다. (표현 = 표현 메타 데이터 + 표현 데이터)
  - 헤더(표현 헤더) : 표현 데이터를 해석할 수 있는 정보 제공한다.
  - 바디(message body) : 표현 데이터. 요청이나 응답에서 전달하는 실제 데이터.
  - `message body`를 `payload` 라고 한다.

## 🍎 HTTP 특징

### 1. 클라이언트와 서버 구조

- 클라이언트와 서버를 분리한다.
  - 이는 클라이언트와 서버가 각각 독립적으로 진화함을 의미한다.
- 클라이언트는 서버에 요청을 보내고, 응답을 대기한다.
- 서버가 요청에 대한 결과를 만들어서 응답을 한다.

### 2. stateless(무상태 프로토콜)

- 서버가 클라이언트의 상태를 보존하지 않는다. 즉, 클라이언트를 구분하지 못한다.

### 3. 비연결성

### 4. HTTP 메시지를 통한 통신

- 단순함, 확장 가능

## 🍎 HTTP 메서드

### 1. GET

- 리소스 조회하는 역할
- 데이터는 query(쿼리 파라미터, 쿼리 스트링)을 통해서 전달.

### 2. POST

- **새 리소스 등록**(생성)
  - ex> /members 얘는 그냥 members에 생성한다. 몇번에 생성될지는 모름.
- **요청 데이터 처리**
  - 단순히 리소스 생성말고도 프로세스를 처리하는 경우에도 사용한다.
  - ex> 결제 완료 → 배달 준비 → 배달 시작 → 배달 완료. 프로세스의 상태를 변경할 때 사용.
  - 예) /orders/{orderId}/start-delivery → 컨트롤 URI이라고 함, 실무에서는 리소스만으론 설계하기 어려움
  - ex) HTML form에 입력한 정보로 회원가입, 주문, 게시판 글쓰기, 댓글달기, 신규 주문 생성, 한 문서 끝에 내용 추가
- **다른 메서드로 처리하기 애매한 경우**
  - ex> JSON으로 조회 데이터를 넘겨야 되는데, GET으로 처리하기 어려운 경우 POST 사용

## 🍎 HTTP 메서드 속성

### 1. 안전 (Safe Methods)

- 호출해도 리소스를 변경하지 않는다.
- GET, POST, PATCH, HEAD 캐시 가능하다.
- 실제로는 GET, HEAD 정도만 캐시로 사용한다.

### 2. 멱등 (Idempotent Methods)

- 몇 번 호출하든 결과가 똑같다.
- 자동 복구 매커니즘에 활용된다. 멱등하면 서버가 TIMEOUT으로 정상 응답을 못했을 때, 클라이언트는 계속 같은 요청으로 보내도 된다.
  - DELETE 할때, 여러 번 호출해도 가능.
- 멱등은 외부 요인으로 리소스가 변경되는 것까지는 고려하지 않는다.

### 3. 캐시 가능 (Cacheavle Methods)

- 응답 결과 리소스를 캐시해도 되는가.

| PATCH       | O                  | O                  | X    | X    | O        |                                                          |
| DELETE      | X                  | O                  | X    | O    | X        | 여러 번 삭제해도 결과는 똑같다                           |
