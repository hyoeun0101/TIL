### 200

- 기본적으로 API가 성공.

### 201

- create 성공

### 204

- delete 성공
- response body가 없음.

### 400 Bad Request

- 잘못된 요청 구문. 유효하지 않은 요청 메시지

### 404 Not found

- get하는데 존재하지 않을 때 발생

### 405 Method Not Allowed

- 서버까지 도달했으나 사용 불가능..?

### 500 Internal Server Error

- 요청을 처리하는 과정에서 서버에 예상치 못한 에러가 발생.
