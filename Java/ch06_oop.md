## 속성=> 변수

### 변수의 종류

| 인스턴스 변수                             | 클래스 변수                    | 지역 변수                  |
| ----------------------------------------- | ------------------------------ | -------------------------- |
| 인스턴스 생성 시 생성                     | 클래스가 메모리 올라갈 때 생성 | 변수 선언문 실행될 때 생성 |
| 인스턴스만의 `고유한 성질` 나타낼 때 사용 | `공통적인 성질` 나타낼 때 사용 |                            |

### 변수의 초기화

- 지역 변수의 초기화는 필수!
- 멤버 변수는 자동 초기화됨.

**멤버 변수 초기화 순서**
`자동 초기화` -> `명시적 초기화` (선언 시 동시 초기화) -> `초기화 블럭` -> `생성자`

- 클래스 초기화 블럭 : 클래스 메모리 올라갈 때 한번만 실행
- 인스턴스 초기화 블럭 : 인스턴스 생성될 때마다 실행

```java
class A{
    static{ System.out.println("static{} 호출");}

    {System.out.println("{} 호출")}

    public A(){System.out.println("생성자 호출")}

    public static void main(String[] args){
        System.out.println("A a1 = new A();");
        A a1 = new A();

        System.out.println("A a2 = new A();");
        A a2 = new A();
    }
}
```

실행결과

```
static{} 호출
A a1 = new A();
{} 호출
생성자 호출
A a2 = new A();
{} 호출
생성자 호출
```

## 기능 => 메서드

### 언제 static 붙일까?

- 인스턴스 멤버 사용하지 않을 때. 인스턴스 생성 필요없이 클래스에서 바로 호출하기 때문에 메서드 호출 시간이 짧아진다.

### 호출 스택

: 메서드 실행을 위한 메모리 할당받은 공간

1. 메서드 호출되면 호출 스택을 할당받음.
2. 메서드 실행하며 지역 변수,매개 변수 저장.
3. 실행 끝나면 메모리 반환하고 스택에서 제거.

### 매개변수

- 기본형 매개변수 : read only
- 참조형 매개변수 : read & write

### 오버로딩 Overloading

: 같은 이름의 메서드 여러 개 정의  
**조건 3가지**

- 메서드 이름 같음.
- 매개 변수의 개수, 타입 순서 달라야함.
- 리턴 타입은 상관 없음.

### 한 파일에 class 여러 개 쓰기

- 한 파일에 public class 하나 있어야하며, 파일 이름과 동일해야함.
- public class가 하나도 없을 시 아무 클래스나 이름으로 작성 가능
- 클래스마다 클래스 파일 (\*.class)가 생성됨.
