
### 🍎 배열을 스트림으로 - stream(), Stream.of()

```java
Stream<String> strStream = Stream.of("a","b","c");
Stream<String> strStream = Stream.of( new String[]{"a","b","c"});
Stream<String> strStream = Arrays.stream(new String[]{"a","b","c"});
Stream<String> strStream = Arrays.stream(new String[]{"a","b","c"},0,3);
```

### 🍎 스트림으로 임의의 수 만들기 - Random().ints()
- 아래는 무한 스트림이라서 limit()으로 제한이 필요.

```java
IntStream intStream = new Random().ints();//무한
intStream.limit(5).forEach(System.out::println);
```

### 🍎 특정 범위의 정수 - range, rangeClosed
- rangeClosed : 시작 숫자부터 끝 숫자까지
```java
IntStream intStream = IntStream.range(1,5);//1,2,3,4
IntStream intStream2 = IntStream.rangeClosed(1,5);//1,2,3,4,5
```

### 🍎 무한 스트림 생성- iterate(), generate()

- `람다식`을 매개변수로 받아서 `무한 스트림` 생성
- iterate(초기값, 람다식) : 값을 누적하며 무한 스트림 생성
- generate(람다식) : 기본형 스트림 타입 다룰 수 없음!!

```java
Stream<Integer> evenStream = Stream.iterate(0,i->i+2);//0,2,4,6,8...
Stream<Integer> randomStream = Stream.generate(Math::random);
Stream<Integer> oneStream = Stream.generate(()->1);//1,1,1...
```

### 🍎 숫자형 스트림 - IntStream, DoubleStream 등
- ㅡ
```java
IntStream evenStream = Stream.iterate(i->i+2).mapToInt(Integer::valueOf);
Stream<Integer> stream = evenStream.boxed();//IntStream -> Stream<Integer>
```

### 🍎 숫자형 스트림 - IntStream, DoubleStream, LongStream
- 숫자형으로 매핑
    - mapToInt, mapToDouble, mapToLong 주로 이 세 메서드는 숫자형 스트림을 반환한다.
```java
int calories = menu.stream()
                    .mapToInt(Dish::getCalories)
                    .sum();
```
- 숫자형 스트림을 기본 스트림으로 변환하기
```java
Stream<Integer> stream = intStream.boxed();
```
