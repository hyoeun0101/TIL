## 🍎 검색과 매칭
- `allMatch`: 모든 요소가 조건 만족하면 true
- `anyMatch`: 한 요소라도 조건 만족하면 true
- `nonMatch`: 모든 요소가 조건 만족하지 않으면 true
    - 이 세 메서드는 쇼트서킷 기법을 활용한다.
    - 예를 들어 allMatch 연산에서 하나라도 false면 연산 멈추고 false 리턴.

```java
//모든 메뉴의 칼로리가 1000이하면 true
boolean isHealthy = menu.stream()
                        .allMatch(dis -> dish.getCalories() < 1000);
```

- `findFirst`: 첫 번째 요소를 반환, 순차 스트림에 사용. 반환값이 없을 수 도있으므로 Optional로 감싼다.
- `findAny`: 스트림 요소에서 아무거나 반환. 병렬 스트림에 사용.
    - 병렬 실행에서는 첫 번째 요소를 찾기 어렵기 때문에 제약이 적은 findAny를 사용한다.
    - 직렬 실행에선 같은 값 나옴.
- `forEachOrdered` : 병렬 처리 때 순서 유지.

```java
// 채소 요리 중 아무거나 반환
Optional<Dish> dish = menu.stream()
                        .filter(Dish::isVegetarian)
                        .findAny()
                        .isPresent(dish -> System.out.println(dish.getName()));//값이 있으면 출력, 없으면 출력 X
```



## 🍎 리듀싱 - reduce
- 스트림의 요소를 하나씩 꺼내면서 누적 계산
- reduce 세 가지
    - reduce(BianryOperator)
        - 초기값 작성안하면 Optional로 감싼 객체 반환
    - reduce(초기값, BinaryOperator)
    - reduce(초기값, BiFunction, BinaryOperator)

```java
Optional<Integer> sum = numbers.stream().reduce((a,b) -> a + b);
```
```java
//최댓값 찾기
int max = intStream.reduce(Integer.MIN_VALUE, (a,b) -> a > b ? a : b);
// 초기값없으면 Optional
Optional<Integer> max = intStream.reduce(Integer::max);

//최솟값 찾기
int min = intStream.reduce(Integer.MAX_VALUE, (a,b) -> a < b ? a : b);
Optional<Integer> min = intStream.reduce(Integer::min);

int count = intStream.reduce(0, (a,b) -> a + 1);//intStream의 요소 개수 반환
```

## 🍎 그룹별로 나눠서 사용할 때 - collect
 - collect 종류 두 가지
    - collect(Supplier, BiConsumer, BiConsumer)
    - collect(Collector)
- 숫자형 스트림은 매개변수 세 개 가진 collect밖에 없어서 boxed()를 한 다음, collect를 사용할 수 있다.

```java
Optional<Integer> max = intStream.boxed().collect(Collectors.reducing(Integer::max));
```

### reduce와 collect
- 스트림 전체는 reduce, 그룹별로 나눠 사용할 때는 collect를 사용한다.
- collect는 누적 계산 후 그 결과를 변환해도 되지만, reduce는 누적하여 계산한 결과를 변환하면 의미적으로 잘 못 사용되는 것이다.
- 병렬 : reduce를 병렬 떄 사용하면 누적값에 대해 동시성 문제가 발생한다. 따라서 병렬 실행 때는 collect를 사용해야 한다.
