### 🍎 Item 57. 지역변수의 범위를 최소화하라.
```
코드의 가독성과 유지보수를 위해 지역변수의 범위를 최소화해야 한다. 가장 처음 쓰일 때 지역변수를 선언하라.
또 선언과 동시에 초기화해야 한다. 반복 변수의 범위를 최소화하기 위해선 while보단 for문이 낫다.
```
- 컬렉션 순회
```java
for(Element e : c) {
    //e로 무엇가 한다.
}
```
- 반복자가 필요한 경우 컬렉션 순회
```java
for(Iterator<Element> i = c.iterator(); i.hasNext();) {
    Element e = i.next();
    // e와 i로 무언가 한다.
}
```
- 지역 변수 최소화하여 반복문 작성
```java
// n의 범위 최소화!
for(int i = 0; n = expensiveComputation(); i < n; i++) {
    // i로 무언가 한다.
}
```

### 🍎 Item 58. 전통적인 for문보다는 for-each 문을 사용하라.

- for-each문을 사용할 수 없는 상황
    1. 파괴적인 필터링 : 컬렉션을 순회하면서 어느 한 요소를 삭제한다면 Collection의 removeIf를 사용하라.
    2. 변형 : 컬렉션을 순회하면서 일부의 값을 변형해야 한다면 인덱스를 사용해야 한다.
    3. 병렬 반복 : 컬렉션을 병렬로 순회해야 한다면 반복자와 인덱스 변수를 사용해 엄격하고 명시적으로 제어해야 한다.

    - 가비지 컬렉터가 네이티브 메모리는 자동 회수하지 못하고, 심지어 추적조차 할 수 없다.
    - 자바 코드와 네이티브 코드의 경계를 넘나들 떄 비용이 발생한다.
    - 가독성도 떨어진다.

### 🍎 Item 68.일반적으로 통용되는 명명 규칙을 따르라.
```
표준 명명 규칙을 체화하여 자연스레 나오게 해라. 
```
- 메서드와 필드명 : camelCase
- 상수명  : ex) FINAL_NAME. 불변 객체도 역시 상수
- 제네릭 타입
    - T : 타입
    - E : 컬렉션 원소
    - K, V : 키, 값
    - R : 메서드의 반환 타입
    - 임의의 시퀀스 타입 : T,U,V 혹은 T1, T2, T3
- 객체를 생성할 수 없는 클래스명 : 복수형 명사. ex> Collectors, Collections
- 인터페이스명 : 클래스와 똑같이 (ex> Collection, Comparator) 또는 able, ible로 끝남 (ex> Runnable, Interable, Accessible)
- boolean을 반환하는 메서드명 : is, has로 시작
- 다른 타입으로 반환하는 메서드명 : toXXXX. ex> toString, toArray
- 객체를 다른 뷰로 보여주는 메서드명 : asXXX. ex>asList
- 객체의 값을 기본 타입으로 반환하는 메서드명 : XXXValue  ex> intValue
