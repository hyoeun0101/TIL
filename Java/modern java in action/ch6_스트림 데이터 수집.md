- Collectors 클래스로 컬렉션 만들고 사용하기
- 스트림 리듀스
- 특별한 리듀싱 요약 연산
- 데이터 그룹화와 분할
- 자신만의 커스텀 컬렉터

- 함수형 프로그래밍에서는 '무엇'을 얻는지에 집중하고, 어떻게 하는지에 대해서는 신경쓰지 않는다.

- 기존 명령형 프로그래밍에서는 우리가 직접 구현하며 작업한다. collect()를 사용하면 Collector가 스트림의 각 요소를 방문하며 알아서 작업을 처리한다. 따라서 가독성과 유지보수성이 좋아진다.

### reduce와 collect 차이

- collect는 누적하여 계산한 결과를 바꿔도 되지만 reduce는 의미론적으로 결과값을 변형하면 안된다.
- reduce는 병렬 실행 시 사용하면 안된다? collect만 병렬 실행 시 사용가능?
  reduce를 병렬 때 사용하면 누적하는 List에 대해 동시성 문제 발생해서.
