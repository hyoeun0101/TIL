# 변수
## 1. 변수란? 
: 데이터(하나의 값)를 저장할 수 있는 공간   
```java
int x; //x라는 저장공간(변수)가 생김
x=10; // 그 공간에 10이 저장됨.
```
-> 변수를 사용하면, 저장 공간 즉 변수에 다른 값만 저장하면 됨. 다른 곳 변경 필요없음.   

## 2. 변수의 타입
: 참조형, 기본형 8개
- 기본형: 실제 값을 저장   
- 참조형: 객체의 주소값을 저장. 기본형을 제외한 나머지 타입.
### [1] 기본형 
: 기본형 변수에는 실제 값을 저장. 기본형의 종류에는 `자료형` 용어를 씀.   
* 기본형의 종류
   
|자료형 종류|자료형|크기|저장 가능 범위|
|----------|------|---|------------|
|논리형|boolean|1byte = 8bit|false, true|
|문자형|char|2byte = 16bit|0 ~ 2^16 - 1|
|정수형|byte|1byte = 8bit|-128 ~ 127|
|정수형|short|2byte = 16bit|-2^15 ~ 2^15 - 1|
|정수형|int|4byte = 32bit|-2^31 ~ 2^31 - 1 (약 20억)|
|정수형|long|8byte = 64bit|-2^63 ~ 2^63 - 1|
|실수형|float|4byte = 32bit|
|실수형|double|8byte = 64bit|

* 정수형의 오버플로우   
: 타입이 표현할 수 있는 값을 넘어서는 것   
- 최대값 + 1 => 최소값   
- 최소값 - 1 => 최대값   
- 부호있는 정수의 오버플로우   
    - char-부호 없음. short-부호 있음

## 3. 상수와 리터럴
- 상수? 변수인데, 한번 저장하면 변경할 수 없음. 변수 앞에 final 붙이기.   
- 리터럴? 우리가 원래 알고 있는 상수. 그 자체로 값을 의미.   
* 리터럴의 타입과 접미사
    - long 타입의 리터럴에 L붙이기
    - float 타입의 리터럴에 f 붙이기
    - double 타입의 리터럴에 d붙이기. 생략가능
    - 문자 리터럴은 반드시 ''안에 하나의 문자가 있어야함. ' '(ok) ''(X)   
    - 문자형 리터럴은 "" ok   


## 4. 타입 간의 변환방법
1. 숫자 -> 문자 : 숫자에 '0' 더하기
    - 3 + '0' => '3'
2. 문자 -> 숫자 : 문자에 '0' 빼기
    - '3' - '0' => 3
3. 숫자 -> 문자열 : 숫자에 빈 문자열 더하기
    - 3 + "" => "3"
4. 문자열 -> 숫자 : parseInt(), parseDouble()
    - Integer.parseInt("3") => 3
    - Double.parseDouble("3.14") => 3.14
5. 문자열 -> 문자 : charAt(0) 사용하기
    - "3".charAt(0) => '3'
6. 문자 -> 문자열 : 빈 문자열 더하기
    - '3' + "" => "3"

7. 문자열 결합
    - 어느 하나에 문자열 더하면 결과값은 문자열
