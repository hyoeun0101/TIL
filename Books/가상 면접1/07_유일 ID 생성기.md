## 🍎 분산 시스템을 위한 유일 ID 생성기 설계
- 고려할 것 : 데이터베이스 서버의 확장성

### 문제 이해 및 설계 범위 확정
- ID는 유일해야 한다.
- ID는 숫자로만 구성되어 있다.
- ID는 64비트로 표현될 수 있다.
- ID는 발급 날짜를 기준으로 정렬할 수 있다.
- 초당 10000개의 ID를 생성할 수 있다.

### 개략적인 설계 방안 제시 
1. 다중 마스터 복제(multi-master replication)
    - 마스터 데이터베이스를 여러 개 생성하고 auto_increment를 사용하여 ID를 생성한다. 단 마스터 데이터베이스의 수만큼 증가시킨다.
    - 마스터1 : 1,4,7  마스터2: 2,5,8  마스터3: 3,6,9
    - 장점 : 데이터베이스 서버의 확장성이 용이하다.
    - 단점 : 여러 데이터 센터에 걸쳐 확장하기 어렵다. ID의 유일성을 보장되지만, 그 값이 시간의 흐름에 따라 커진다는 보장X, 서버를 추가, 삭제 시 잘 동작하도록 만들기 어렵다.

2. UUID
    - 128비트짜리 수, 웹 서버마다 ID 생성기가 있다.
    - 장점 : 간단, 동기화 이슈 없음, 규모 확장도 쉬움
    - 단점 : 128비트로 길다, 시간 순으로 정렬X, 숫자아닌 값이 포함
