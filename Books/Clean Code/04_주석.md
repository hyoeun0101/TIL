## 🍎 주석은 나쁘다?
### 주석을 사용하지 말고 코드로 표현하라.
- 실제로 주석의 설명대로 동작하지 않는 코드들을 많이 보았다. 주석을 사용하지 말고, 명확한 이름을 짓어서 코드에 의도를 명확하게 표현해야 한다.

##  🍎 좋은 주석 (어떤 주석은 정말 필요하고 유익하다)
- 법적인 주석
- 각 소스 파일 첫머리에 추가한 표준 주석 헤더. 법적인 이유로 저작권 정보와 소유권 정보 등을 나타내는 주석들.
- 정보를 제공하는 주석 
- 의도를 설명하는 주석
- 의도를 명료하게 밝히는 주석
- 결과를 경고하는 주석
- TODO 주석
- 중요성을 강조하는 주석
- 공개 API 에서 Javadocs
