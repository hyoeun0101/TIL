## 🍎네비게이션 가드
- 라우터에서 다른 라우터로 이동할 때 네비게이션이 실행되어 라우터의 이동을 막거나 어떠한 처리를 하는 기능.
- 적용 범위에 따라 전역 가드, 라우트별 가드, 컴포넌트별 가드로 나뉜다.

## 🍎 전역 가드
### Global Guard: beforeEach
- router.beforeEach를 사용하여 보호하기 이전에 전역 등록을 할 수 있다.

```javascript
const router = new VueRouter({...});

router.beforeEach((to, from, next) => {

});
```
- 가드는 비동기식으로 실행될 수 있으며 네비게이션

- 전역에서 동작한다.
- beforeEach, beforeResolve, afterEach가 있다.
- to : 다음에 이동할 라우트
- from : 현재 라우트로 오기전 라우트
- next : 이 함수가 호출되어야 다음 라우트로 이동 시작한다.호출되지 않으면 이동하지 않음!
  - next()
  - next(false) : 현재 네비게이션을 중단.
  - next('/') 또는 next({ path : '/' }) : 해당 위치로 리다이렉션. 현재 네비게이션 중단되고 새 네비게이션이 시작.
  - next(error) : next에 전달된 인자가 Error의 인스턴스이면 탐색 중단되고 router.onError() 실행.


### Global Resolve Guard : beforeResolve
- router.beforeResolve를 사용하여 글로벌 가드를 등록할 수 있음. router.beforeEach와 비슷하지만 beforeResolve는 모든 컴포넌트 가드와 비동기 라우트 컴포넌트를 불러온 후 네비게이션 가드를 확인하기 전에 호출된다.

### Global After Hooks : afterEach
- 가드와 달리 훅은 next 함수를 얻지 못하며 네비게이션에 영향을 줄 수 없다.
- to, from 두 가지 인자를 받음. 네비게이션 작업 끝난 다음 실행되기 때문에 next가 필요없다.

## 🍎 라우트 가드
- 특정 url, 즉 라우트마다 가드를 설정할 수 있다.
### beforeEnter
- 이동하려는 라우트에 진입하기 전 호출되는 훅.  
- beforeEach는 전역이지만 beforeEnter는 라우트마다 다르게 가드를 지정할 수 있다.

```javascript
const router = new VueRouter({
  routes: [
    {
      path: '/foo',
      component: Foo,
      // 라우트 설정 객체에 직접 정의할 수 있음.
      beforeEnter: (to, from, next) => {
        //...
      }
    }
  ]
});
```

## 🍎 전체 네비게이션 시나리오
1. 네비게이션이 트리거됨.
2. 비활성화될 컴포넌트에서 가드를 호출.
3. 전역 beforeEach 가드 호출.
4. 재사용되는 컴포넌트에서 beforeRouteUpdate 가드 호출. (2.2 이상)
5. 라우트 설정에서 beforeEnter 호출.
6. 비동기 라우트 컴포넌트 해결.
7. 활성화된 컴포넌트에서 beforeRouteEnter 호출.
8. 전역 beforeResolve 가드 호출. (2.5이상)
9. 네비게이션 완료.
10. 전역 afterEach 훅 호출.
11. DOM 갱신 트리거 됨.
12. 인스턴스화 된 인스턴스들의 beforeRouteEnter가드에서 next에 전달 된 콜백을 호출합니다.



## 🍎컴포넌트 내부 가드

- 컴포넌트 안에서 라우트를 정의할 수 있다.

### beforeRouteEnter

- 컴포넌트를 랜더링하는 라우트 앞에서 호출된다.
- 이 가드가 호출될 때 컴포넌트는 아직 생성되지 않았기 때문에 this로 컴포넌트 인스턴스에 접근할 수 없다.

```javascript
const Foo = {
  beforeRouteEnter(to, from, next) {
    next((vm) => {
      //vm을 통해서 컴포넌트 인스턴스에 접근할 수 있다.
    });
  },
};
```

### beforeRouteLeave

- 컴포넌트를 랜더링하는 라우트가 이전으로 네비게이
- beforeRouteLeave 안에서 this에 직접 접근할 수 있다.
- 사용자가 저장하지 않은 내용을 두고 다른 라우트로 이동하는 것을 방지할 때 사용한다.

### beforeRouteUpdate (2.2버전에 추가)

- 컴포넌트를 재사용할 때 실행되는 훅.
- 동적 라우터를 사용할 때 이는 동일한 컴포넌트를 재사용하는 것이다.
- 예를 들어 `/post:post_id` 라우터가 있으면 `/post/1`에서 `/post/2`로 이동할 때 이는 새로운 컴포넌트를 가져오는 것이 아니라 기존의 컴포넌트를 재사용하는 것이다.
