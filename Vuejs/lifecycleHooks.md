## 라이프 사이클 훅

![lifecycle](https://user-images.githubusercontent.com/96059261/205774337-21f4778d-b36f-4b66-9a1a-d1924318cb68.jpg)

- 라이프 사이클 훅을 크게 나누면 `인스턴스의 생성`, `생성된 인스턴스를 화면에 부착`, `화면에 부착된 인스턴스의 내용 갱신`, `인스턴스 소멸` 4단계로 이루어진다.

## 라이프 사이클 속성

### 1. beforeCreate

- 인스턴스 생성되고, 제일 먼저 실행됨.
- data, methods 속성이 정의되지 않아 접근할 수 없으며, 마찬가지로 DOM 요소에도 접근할 수 없다.

### 2. created

- data, methods 속성에 접근 가능
- 아직 인스턴스가 화면 요소에 부착되지 전이기 때문에 template 속성에 정의된 돔 요소에 접근 불가능

### 3. beforeMount

- template 속성에 지정한 마크업 속성(HTML, CSS)을 render() 함수로 변환
  - render()란? 자바스크립트로 화면의 돔을 그리는 함수
- el속성에 지정한 돔에 인스턴스를 부착되기 전에 호출된다.
- render() 함수가 호출되기 직전의 로직을 추가하기 좋다.
  - el속성? HTML 요소들을 말하는 것 같다.

### mounted

- 돔 요소에 인스턴스가 부착되면 호출된다.
- 돔 요소에 접근 가능하여 화면 요소를 제어하는 로직을 수행하기 좋은 단계이다.
- 단, 돔에 인스턴스가 부착되자마자 호출되기 때문에 하위 컴포넌트나 외부 라이브러리에 의해 추가된 요소들이 최종 HTML 코드로 변환되는 시점과 다를 수 있다.(?)

### beforeUpdate

- 관찰하고 있는 데이터가 변경되면 가상 돔으로 화면을 다시 그리기 전에 호출된다.
  - 돔 요소가 화면에 부착되고 나면 인스턴스에 정의한 속성들이 화면에 치환된다. 치환된 값은 `$watch`로 감시한다.(이를 데이터 관찰이라고 함)
- 변경 예정인 새 데이터에 접근할 수 있고, 변경 예정인 로직을 미리 넣을 수 있다. 변경하는 로직을 넣어도 화면이 다시 그려지지는 않는다.

### updated

- 데이터가 변경되면 가상 돔으로 화면을 다시 그린 다음 바로 호출된다.
- 다시 말해, 데이터 갱신 후 재랜더링 완료 상태이다.
- 이 단계에서 데이터 값을 변경하면 무한 루프에 빠질 수 있기 때문에 값을 변경하려면 computed, watch를 사용해야 한다.
- 데이터 값을 갱신하는 로직은 가급적이면 beforeUpdate에 넣고, udpated에서는 재랜더링 된 돔과 관련된 로직을 추가하는 것이 좋다.

### beforeDestroy

- 뷰 인스턴스가 소멸되기 전에 호출된다.
- 아직 인스턴스에 접근은 할 수 있기 때문에 인스턴스의 데이터를 삭제하기 좋은 단계이다.

### destroyed

- 뷰 인스턴스가 소멸되고 나서 호출된다.
- 뷰 인스턴스의 모든 속성이 제거되며, 하위에 선언한 인스턴스도 소멸된다.

## 컴포넌트

- 전역 컴포넌트 등록 : 한번 등록하면 전체 영역에서 사용가능하다.

```javascript
Vue.component("my-global-component", {
  template: "<p>전역 컴포넌트입니다.</p>",
});
```

- 지역 컴포넌트 : 새 인스턴스 생성마다 등록해줘야하며 해당 인스턴스에서만 사용 가능하다.

```javascript
var cmp = {
  template: "<p>지역 컴포넌트입니다.</p>",
};
new Vue({
  components: {
    "my-local-component": cmp,
  },
});
```

## 컴포넌트 동작 순서

1. Vue 라이브러리 파일 읽어온다.
2. 뷰 생성자로 컴포넌트를 등록한다.
3. 뷰 인스턴스를 생성한다.
4. 특정 화면에 인스턴스를 부착한다.
5. 인스턴스 내용을 토대로 화면을 변환한다.

**각 컴포넌트는 서로 참조할 수 없다. 단 상위 컴포넌트와 하위 컴포넌트만이 서로 참조할 수 있다.**

1. 상위 컴포넌트가 하위 컴포넌트에게 `데이터를 전달`할 때는 `props`를 통해 전달한다.
2. 하위 컴포넌트에서 상위 컴포넌트로 `이벤트를 전달`할 수 있다. `$emit`을 사용하여 이벤트 객체를 전달한다.
3. 같은 레벨의 컴포넌트끼리의 통신은 이벤트 버스를 통해 전달할 수 있다.
