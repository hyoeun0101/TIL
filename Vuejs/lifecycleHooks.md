1. `beforCreat()` : 여기서 변수를 가져오면 읽을 수 없음. 아직 읽기 전

```

```

2. `created()`: 여기서 읽기 가능, 돔 요소에 접근하지 못함

```
템플릿 컴파일
```

3. `beforeMount()`: 여기서 아직 태그 못읽음

```
DOM 노드 생성 및 삽입(html 생성)
```

4. `mounted()` : 태그(돔 요소) 읽기 가능,초기 렌더링과 DOM노드 생성 완료 후 코드를 실행하는 데 사용.

## 컴포넌트

- 전역 컴포넌트 등록 : 한번 등록하면 전체 영역에서 사용가능하다.

```javascript
Vue.component("my-global-component", {
  template: "<p>전역 컴포넌트입니다.</p>",
});
```

- 지역 컴포넌트 : 새 인스턴스 생성마다 등록해줘야하며 해당 인스턴스에서만 사용 가능하다.

```javascript
var cmp = {
  template: "<p>지역 컴포넌트입니다.</p>",
};
new Vue({
  components: {
    "my-local-component": cmp,
  },
});
```

## 컴포넌트 동작 순서

1. Vue 라이브러리 파일 읽어온다.
2. 뷰 생성자로 컴포넌트를 등록한다.
3. 뷰 인스턴스를 생성한다.
4. 특정 화면에 인스턴스를 부착한다.
5. 인스턴스 내용을 토대로 화면을 변환한다.

**각 컴포넌트는 서로 참조할 수 없다. 단 상위 컴포넌트와 하위 컴포넌트만이 서로 참조할 수 있다.**

1. 상위 컴포넌트가 하위 컴포넌트에게 `데이터를 전달`할 때는 `props`를 통해 전달한다.
2. 하위 컴포넌트에서 상위 컴포넌트로 `이벤트를 전달`할 수 있다. `$emit`을 사용하여 이벤트 객체를 전달한다.
3. 같은 레벨의 컴포넌트끼리의 통신은 이벤트 버스를 통해 전달할 수 있다.
