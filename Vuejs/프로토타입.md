자바스크립트는 프로토타입 기반 언어이다. 어떤 객체를 프로토타입으로 삼고 그것을 참조함으로써 상속을 얻는다.

prototype 내부에는 인스턴스가 사용할 메서드와 속성을 정의한다.
모든 함수는 prototype 속성을 자동으로 가지고 있으며 `__proto__` 속성이 자동 생성된다. 이 속성은 생략 가능하며 인스턴스에서 자신의 것처럼 prototype의 메서드와 속성에 접근이 가능하다.

`인스턴스에서 생성자 함수의 prototype 속성을 참조하는 `**proto**`를 생략하면, 인스턴스는 바로 prototype의 메서드와 속성에 접근할 수 있다.`

# Vue.prototype.$앱이름

: 인스턴스 프로퍼티 사용하기  
여러 컴포넌트에서 사용하고 싶은 함수, 데이터를 global scope에 영향을 받지 않도록 따로 prototype에 정의한다. prototype에 함수를 정의하면 각 Vue 인스턴스에서 호출하여 사용할 수 있다.
