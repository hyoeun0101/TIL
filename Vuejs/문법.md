## computed

- data의 값을 계산하는 메서드를 넣을 수 있다. 계산 후 출력

```javascript
<template>
  <div>
    <section v-if="hasFruit">
      <ul>
        <li v-for="fruit in fruits" :key="fruit">{{ fruit }}</li>
      </ul>
    </section>
    <h1>Reverse Fruits</h1>
    <ul>
      <li v-for="fruit in reverseFruits" :key="fruit">{{ fruit }}</li>
    </ul>
  </div>
</template>
<script>
export default {
  data() {
    return {
      fruits: ['apple', 'banana', 'cherry']
    }
  },
  computed: {
    hasFruit() {
      return this.fruits.length > 0
    },
    reverseFruits() {
      return this.fruits.map((fruit) => {
        return fruit.split('').reverse().join('')
      })
    }
  }
}
</script>

```

- `캐싱` 기능이 있다. 값이 변하지 않으면 캐싱된 것을 불러온다. methods는 함수 호출 시 계속 호출을 하지만 computed는 한번 호출 후 캐싱을 한다. 아래 reverseMessage를 세 번 호출하고 있지만 실제로 호출되는 횟수는 1번이다.

```javascript
<template>
  <div>
    <h1>{{ reverseMessage }}</h1>
    <h1>{{ reverseMessage }}</h1>
    <h1>{{ reverseMessage }}</h1>
  </div>
</template>

<script>
export default {
  data() {
    return {
      msg: 'Hello Computed!'
    }
  },
  computed: {
    reverseMessage() {
      return this.msg.split('').reverse().join('')
    }
  }
}
</script>

```

## getter, setter

기본적으로 computed는 값을 읽기만 하기때문에 getter역할을 한다.  
data의 값은 getter, setter역할 둘다 한다.
computed도 setter역할을 하려면 속성으로 작성해주면 된다.

```javascript
<template>
  <div>
    <button @click="add()">add</button>
    <h1>{{ reverseMessage }}</h1>

  </div>
</template>

<script>
export default {
  data() {
    return {
      msg: 'Hello Computed!'
    }
  },
  computed: {
    reverseMessage: {
      get() {
        return this.msg.split('').reverse().join('')
      },
      set(value) {
        this.msg = value
      }
    }
  },
  methods: {
    add() {
      this.reverseMessage += '!?'
    }
  }
}
</script>
```

처음 reverseMessage는 get을 통해 반환이 되고, add 버튼을 누르면 set이 호출되고 값을 변경한 다음, 다시 get으로 값을 읽는다.

## watch

: 내용이 변경되었을 때 감시하는 역할.

```javascript
<template>
  <div>
    <button @click="changeMsg()">add</button>
    <h1>{{ reverseMessage() }}</h1>
</template>

<script>
export default {
  data() {
    return {
      msg: 'Hello Computed!'
    }
  },
  computed: {
    reverseMessage(){
        return this.msg.split('').reverse().join('')
    }
  },
  watch:{
    msg(){
        console.log('msg=',this.msg)
    }
  }
  methods: {
    changeMsg() {
      this.msg ='Good!'
    }
  }
}
</script>
```

watch에 msg를 작성하면 msg값이 변할 때 실행이된다. `msg(value)`로 작성할 수 도 있는데 이때 value는 변경된 값을 의미한다.

div 로 특정 태그들을 묶고 v-if 조건을 주어서 태그가 보이게 안보이게 할 수 있다. 하지만 div로 감싸면 div가 감싸진 채로 출력이 된다.

## v-show

v-if과 v-show 의 차이점?  
v-if는 false이면 DOM에 랜더링 되지 않는다. 조건에 따라 랜더링 될 것인지 안될 것인지 바뀌기 때문에 lazy하다. 전환 비용이 높다.  
반면 v-show는 랜더링은 되는데 `display:none`을 넣어주는 것이다. CSS 속성만 제어해주면 되기때문에 간단하다. 그래서 전환을 많이 한다면 v-show를 사용하는게 좋다.

## 이벤트 핸들링

아래에서 e는 이벤트 객체이다.

```javascript
<template>
  <div>
    <button @click="handler">click!</button>
  </div>
</template>
<script>
export default {
  components: {},
  data() {
    return {}
  },
  methods: {
    handler(e) {
      console.log(e)
    }
  }
}
</script>

```

@click에서 handler('value', $event)를 넘겨주면 문자와 이벤트 객체가 출력된다. 다수의 메서드를 호출하려면 메서드 뒤에 괄호를 붙여줘야한다.`@click="method1() method2()"` 이렇게.

## 이벤트 핸들링 - 이벤트 수식어

- @click.prevent : event.prventDefult()와 같음.함수 실행 되고 그 이후의 동작을 막음. 콘솔 찍히고 네이버 안들어가짐.
- @click.once : 한번만 동작
- @click.prvent.once : 처음 클릭하면 콘솔찍히고, 네이버 안들어가짐. 두 번째 클릭은 콘솔 안찍히고 들어가짐.

```javascript
<template>
    <div>
        <a href="https://naver.com"
        target="_blank"
        @click="handler">
        Naver
        </a>
    </div>
</template>
<script>
export default {
    methods: {
        handler(){
            console.log("cal handler")
        }
    }
}</script>

  </template
```

## 이벤트 버블링

child를 클릭하면 parent도 클릭하는 것이기 때문에 parent의 click도 동작한다. child 클릭 실행 다음 parent 클릭 실행. 이벤트가 부모로 타고 올라가 동작함. `B출력 후 A 출력`

```javascript
<template>
    <div>
        <div class="parent" @click="handlerA">
            <div class="child" @click="handlerB"></div>
        </div>
    </div>
</template>
<script>
export default {
    methods: {
        handlerA(){
            console.log("A")
        },
        handlerB(){
            console.log("B")
        }

    }
}</script>

```

이를 방지하기 위해선 child에서 다음과 같이 작성하여 이벤트 전파를 막을 수 있다.

```javascript
handlerB(e){
    e.stopPopagation()
}
또는
@click.stop="handlerB"
```

## 이벤트 캡쳐링

이벤트 버블링의 반대. 부모 요소에서 자식 요소로 내려오는 것. 자식을 클릭했는데 A출력 후 B출력하려면 다음과 같이 작성한다.

```javascript
@click.capture="handlerA"
```

- click.self 는 부모-자식 상관없이 자신의 영역 클릭했을 때 동작.

- @wheel.passive : 휠과 함수와 분리되어 동작
- @keydown.key="함수"

  - key는 키보드키 의미

- v-model.lazy="msg" : 변경내용 작성 후 다른 곳 클릭해야 msg 값이 변경됨.

## 컴포넌트의 상속

컴포넌트에 속성을 작성하면 그 속성들은 template에서 최상위 요소에게 상속이 된다. 컴포넌트에 class="parent"라는 속성을 작성했다면 template에서 최상위 요소에 class="parent"가 생성된다.

```
export default{
  inheritAttrs: false
}
```

: 컴포넌트로부터 상속받지 않는다.

- 다만 최상위 요소가 여러 개라면 어느 요소에게 상속할지 모르기 때문에 상속이 되지 않는다. 그러니 최상위 요소에서 어느 요소에게 상속할 것인지 작성해줘야한다. 상속받을 요소에게 v-bind="$attrs"를 작성한다.
  [Child.vue]

```javascript
<template>
  <div v-bind="$attrs"></div>
</template>
```

## provide & inject

보통 부모에서 자식에게 값을 넘겨줄 때, props를 이용하여 넘겨준다. 그런데 부모1 - 부모2 - 자식 관계에서 부모1에서 바로 자식에게 값을 넘겨주려면 어떻게 해야할까?  
바로 provide, inject를 사용하면 된다.  
하지만 이것은 반응성이 없다. 한번 값을 전달해줄 뿐이다. 반응형으로 하고 싶다면 computed를 이용하여 값을 계산한 뒤 넘겨줘야한다.  
[App.vue]

```javascript
<template>
  <button @click="message='GGG'">click</button>
  <Parent/>
  <h1>App: {{message}}</h1>
</template>
<script>
import Parent from './components/Parent.vue'
import {computed} from 'vue'
export default {
  components: {
    Parent
  },
  data(){
    return{
      message:'heelelele'
    }
  },
  provide(){
    return{
      msg: computed(() =>this.message)
    }
  }
}
</script>
```

[Child.vue]

```javascript
<template>
    <h1>child:{{msg}}</h1>
</template>
<script>
export default {
    inject:['msg']
}
</script>

```
