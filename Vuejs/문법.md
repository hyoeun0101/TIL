## computed

- data의 값을 계산하는 메서드를 넣을 수 있다. 계산 후 출력

```javascript
<template>
  <div>
    <section v-if="hasFruit">
      <ul>
        <li v-for="fruit in fruits" :key="fruit">{{ fruit }}</li>
      </ul>
    </section>
    <h1>Reverse Fruits</h1>
    <ul>
      <li v-for="fruit in reverseFruits" :key="fruit">{{ fruit }}</li>
    </ul>
  </div>
</template>
<script>
export default {
  data() {
    return {
      fruits: ['apple', 'banana', 'cherry']
    }
  },
  computed: {
    hasFruit() {
      return this.fruits.length > 0
    },
    reverseFruits() {
      return this.fruits.map((fruit) => {
        return fruit.split('').reverse().join('')
      })
    }
  }
}
</script>

```

- `캐싱` 기능이 있다. 값이 변하지 않으면 캐싱된 것을 불러온다. methods는 함수 호출 시 계속 호출을 하지만 computed는 한번 호출 후 캐싱을 한다. 아래 reverseMessage를 세 번 호출하고 있지만 실제로 호출되는 횟수는 1번이다.

```javascript
<template>
  <div>
    <h1>{{ reverseMessage }}</h1>
    <h1>{{ reverseMessage }}</h1>
    <h1>{{ reverseMessage }}</h1>
  </div>
</template>

<script>
export default {
  data() {
    return {
      msg: 'Hello Computed!'
    }
  },
  computed: {
    reverseMessage() {
      return this.msg.split('').reverse().join('')
    }
  }
}
</script>

```

## getter, setter

기본적으로 computed는 값을 읽기만 하기때문에 getter역할을 한다.  
data의 값은 getter, setter역할 둘다 한다.
computed도 setter역할을 하려면 속성으로 작성해주면 된다.

```javascript
<template>
  <div>
    <button @click="add()">add</button>
    <h1>{{ reverseMessage }}</h1>

  </div>
</template>

<script>
export default {
  data() {
    return {
      msg: 'Hello Computed!'
    }
  },
  computed: {
    reverseMessage: {
      get() {
        return this.msg.split('').reverse().join('')
      },
      set(value) {
        this.msg = value
      }
    }
  },
  methods: {
    add() {
      this.reverseMessage += '!?'
    }
  }
}
</script>
```

처음 reverseMessage는 get을 통해 반환이 되고, add 버튼을 누르면 set이 호출되고 값을 변경한 다음, 다시 get으로 값을 읽는다.

## watch

: 데이터 변경 시 호출됨.

```javascript
<template>
  <div>
    <button @click="changeMsg()">add</button>
    <h1>{{ reverseMessage() }}</h1>
</template>

<script>
export default {
  data() {
    return {
      msg: 'Hello Computed!'
    }
  },
  computed: {
    reverseMessage(){
        return this.msg.split('').reverse().join('')
    }
  },
  watch:{
    msg(){
        console.log('msg=',this.msg)
    }
  }
  methods: {
    changeMsg() {
      this.msg ='Good!'
    }
  }
}
</script>
```

watch에 msg를 작성하면 msg값이 변할 때 실행이된다. `msg(value)`로 작성할 수 도 있는데 이때 value는 변경된 값을 의미한다.

## tempalte

div 로 특정 태그들을 묶고 v-if 조건을 주어서 태그가 보이게 안보이게 할 수 있다. 하지만 div로 감싸면 div가 감싸진 채로 출력이 된다.  
감싸지지 않도록 div 대신에 template를 사용하자. 다만 최상위 template에 v-if는 적용이 안되니 주의하자.

## v-show

v-if과 v-show 의 차이점?  
v-if는 false이면 DOM에 랜더링 되지 않는다. 조건에 따라 랜더링 될 것인지 안될 것인지 바뀌기 때문에 lazy하다. 전환 비용이 높다.  
반면 v-show는 랜더링은 되는데 `display:none`을 넣어주는 것이다. CSS 속성만 제어해주면 되기때문에 간단하다. 그래서 전환을 많이 한다면 v-show를 사용하는게 좋다.


## slot

컴포넌트 사이 내용을 넣으면, vue에서 <slot></slot> 에 그 내용이 들어간다. slot안에 내용이 있어도 컴포넌트 사이의 내용으로 대체된다.

- v-slot 의 약어 : #
  slot에 이름 지정해줘서 원하는 곳에 내용 넣기  
  [App.vue] - 상위 컴포넌트

```javascript
<template>
  <div>
    <MyBtn>
      <template #icon>
          <span>Banana</span>
      </template>
      <template #text>
          <span>(B)</span>
      </template>
    </MyBtn>
  </div>
</template>

<script>
import MyBtn from './components/MyBtn.vue'
export default {
  components: {
    MyBtn
  }
}
</script>
```

[MyBtn.vue] - 하위 컴포넌트

```javascript
<template>
    <div class="btn">
      <slot name="icon"></slot>//#icon이 여기로 들어옴.
      <slot name="text"></slot>//#text가 여기로 들어옴
    </div>
</template>
<script>
export default {
}
</script>

<style scoped>
.btn {
  display: inline-block;
  margin: 4px;
  padding: 6px 12px;
  border-radius: 4px;
  color: white;
  background-color: gray;
  cursor: pointer;
}
.btn.large{
  font-size:20px;
  padding: 10px 20px;
}
</style>


```

## 컴포넌트의 상속

컴포넌트에 속성을 작성하면 그 속성들은 template에서 최상위 요소에게 상속이 된다. 컴포넌트에 class="parent"라는 속성을 작성했다면 template에서 최상위 요소에 class="parent"가 생성된다.

```
export default{
  inheritAttrs: false
}
```

: 컴포넌트로부터 상속받지 않는다.

- 다만 최상위 요소가 여러 개라면 어느 요소에게 상속할지 모르기 때문에 상속이 되지 않는다. 그러니 최상위 요소에서 어느 요소에게 상속할 것인지 작성해줘야한다. 상속받을 요소에게 v-bind="$attrs"를 작성한다.
  [Child.vue]

```javascript
<template>
  <div v-bind="$attrs"></div>
</template>
```

## provide & inject

보통 부모에서 자식에게 값을 넘겨줄 때, props를 이용하여 넘겨준다. 그런데 부모1 - 부모2 - 자식 관계에서 부모1에서 바로 자식에게 값을 넘겨주려면 어떻게 해야할까?  
바로 provide, inject를 사용하면 된다.  
하지만 이것은 반응성이 없다. 한번 값을 전달해줄 뿐이다. 반응형으로 하고 싶다면 computed를 이용하여 값을 계산한 뒤 넘겨줘야한다.  
[App.vue]

```javascript
<template>
  <button @click="message='GGG'">click</button>
  <Parent/>
  <h1>App: {{message}}</h1>
</template>
<script>
import Parent from './components/Parent.vue'
import {computed} from 'vue'
export default {
  components: {
    Parent
  },
  data(){
    return{
      message:'heelelele'
    }
  },
  provide(){
    return{
      msg: computed(() =>this.message)
    }
  }
}
</script>
```

[Child.vue]

```javascript
<template>
    <h1>child:{{msg}}</h1>
</template>
<script>
export default {
    inject:['msg']
}
</script>

```

# ref, $refs

ref 속성을 통해 DOM요소에 접근할 수 있다.

```javascript
<template>
  <h1 ref="hello">Hello World!</h1>
</template>
<script>
export default {
  mounted(){
    const h1El = this.$refs.hello
    console.log(h1El.textContext)//Hello World! 출력
  }
}
</script>
```

```javascript
<button @click="clickBtn" ref="myButton">Click me!</button>

...

export default{
  data:{
    message:"hello"
  }
  methods:{
    clickBtn(){
      console.log(this.$refs);
      this.$refs.myButton.innerText = this.message;
    }
  }
}
```

- ref 속성을 추가하고 $refs로 접근해보면 DOM 요소가 출력되는 것을 볼 수 있다.
- DOM 요소에 접근하는 것이기 때문에 mounted 이후에 접근할 수 있다.
- class, id에 의존하지 않았기 때문에 더 안전하다.
- v-for과 같이 사용하면 반복하는 DOM 요소를 배열로 가지게 된다.

```javascript
<h1 v-for="n in 10" :key="n" ref="numbers"></h1>
```

## 체크박스 값

- 체크하면 true, 안하면 false

```html
<input type="checkbox" v-model="agreement" />
```

- 자동으로 agreement의 타입은 boolean이다.
- true,false 대신 다른 값을 주고 싶으면 true-value, false-value을 작성하면 된다.

```html
<input type="checkbox" v-model="agreement" true-value="Y" false-value="N" />
```
