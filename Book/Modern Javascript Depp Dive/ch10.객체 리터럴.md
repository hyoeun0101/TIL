## 10.1 객체란?
- 객체는 0개 이상의 프로퍼티로 구성된 집합
- 객체의 구성 = `값(프로퍼티)` + `동작(메서드)`
- `프로퍼티` = 키 + 값 
```javascript
//객체 person
var person = {
    name: 'Lee', //프로퍼티1
    age: 20 //프로퍼티2
}
```
- 원시 타입은 변경 불가능(immutable), 객체 타입은 변경 가능(mutable)
- `메서드` : 프로퍼티 값이 함수일 때, 이 함수는 메서드라고 부름

```javascript
//객체
var counter = {
    num: 0, //프로퍼티
    increase: function() { //메서드
        this.num++;
    }
};

var counter = {
    num: 0,
    increase() { //메서드 축약 표현
        this.num++;
    }
};
```

## 10.2 객체 생성

- 자바,C언어 = `클래스` 기반 객체지향 언어. 따라서 new 연산자로 객체 생성
- 자바스크립트 = `프로토타입` 기반 객체지향 언어 객체 생성하는 다양한 방법 지원
- 객체 생성하는 법
    - 객체 리터럴
    - Object 생성자 함수
    - 생성자 함수
    - Object.create 메서드
    - 클래스(ES6)

```javascript
// 객체 리터럴
ver person = {
    name: 'Lee',
    sayHello: function() {
        console.log(`Hello! My name is ${this.name}.`);
    }
}; //객체 리터럴의 닫는 중괄호 뒤에 세미콜론 붙인다!

console.log(typeof person); //object
console.log(person); //{name: "Lee", sayHello: f}
```

## 10.3 프로퍼티
- 프로퍼티는 키와 값으로 구성

```javascript
var person = {
    firstName: 'Ung-mo',
    'last-name': 'Lee' //식별자 네이밍 규칙 준수하지 않을 경우 -> 따옴표 붙이기
};
```

### 프로퍼티 접근
- 마침표 or 대괄호
- 객체에 존재하지 않는 프로퍼티는 undefined이다.
```javascript
var person = {
    name: 'Lee'
};

console.log(person.name); //Lee
console.log(person['name']); //Lee

console.log(person.age); //undefined -> 객체에 존재하지 않는 프로퍼티
```

### 프로퍼티 동적 생성
```javascript
var person = {
    name: 'Lee'
};

person.age = 20;

console.log(person); //{name: "Lee", age: 20}
```
### 프로퍼티 삭제
```javascript
var person = {
    name: 'Lee'
};

person.age = 20;

delete person.age; //age 프로퍼티 삭제

delete person.address; // 없는 프로퍼티 삭제해도 에러 발생하지 않음.
```

### ES6 추가딘 객체 리터럴의 확장 기능
- 프로퍼티 축약 표현
```javascript
var x = 1, y = 2;

var obj = {
    x: x,
    y: y
};

console.log(obj); //{x: 1, y:2}

//프로퍼티 축약
var obj = { x,y };
```
 
- 프로퍼티 키 동적 생성
```javascript
var prefix = 'prop';
var i = 0;

var obj = {};

obj[prefix + '-' + ++i] = i;
obj[prefix + '-' + ++i] = i;
obj[prefix + '-' + ++i] = i;

// {prop-1: 1, prop-2: 2, prop-3: 3}
```
