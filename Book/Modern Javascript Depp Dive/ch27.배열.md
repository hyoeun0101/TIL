## 27.1 배열이란?
- 배열은 여러 값을 순차적으로 나열한 자료구조.
- 자바스크립트에서 배열은 `객체 타입`이다.

- 배열 생성하는 방법
    - 배열 리터럴
    - Array 생성자 함수
    - Array.of 메서드
    - Array.from 메서드
- 배열의 프로토타입 객체는 Array.prototype이다.
```javascript
const arr = [1,2,3];

arr.constructor === Array; // true
Object.getPrototypeOf(arr) === Array.prototype; // true
```
- 배열은 일반 객체와 다르게 `length` 프로퍼티를 가진다.

## 27.2 자바스크립트 배열은 배열이 아니다

### 자료구조의 배열
- 요소가 메모리에 연속적으로 인접해 있음, 하나의 데이터 타입 = 밀집 배열 (dense array)
- 인덱스로 요소에 접근 : O(1)
    - 검색 대상 요소의 메모리 주소 = 배열 시작 메모리 주소 + (인덱스 * 요소의 바이트 수)
- 요소 검색 : O(n)
- 삽입, 삭제 : 요소 이동 필요

### 자바스크립트의 배열
- 배열의 요소가 인접하고 있지 않다, 어떤 타입의 값이 와도 됨. = 희소 배열
- 인덱스 문자열이 프로퍼티 키, 요소가 프로퍼티 값.
- 자바스크립트 배열은 해시 테이블로 구현된 객체
- 검색은 일반적인 배열보다 느리지만 삭제, 삽입은 일반적인 배열보다 빠름.
