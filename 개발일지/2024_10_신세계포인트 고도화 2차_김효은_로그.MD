__🍎 Mybais에서 Interval에 변수 사용법 - CAST 활용__
1. 내가 원하는 동작    
	: 5minute의 5를 변수로 사용하고 싶다.
```sql
SELECT COUNT(*)
FROM 2FACTOR_SEND SEND
WHERE SEND.RESTRICT_DT > NOW() - interval '5minute'
```
2.  시도 1:  아래처럼 작성하니 오류 발생 ($3 잘못된 syntax라며..)
```sql
SELECT COUNT(*)
FROM 2FACTOR_SEND SEND
WHERE SEND.RESTRICT_DT > NOW() - interval #{standardTime} || 'minute'
```

3. 해결 : cast를 사용해서 해결~
```sql
SELECT COUNT(*)
FROM 2FACTOR_SEND SEND
WHERE SEND.RESTRICT_DT > NOW() - CAST(#{standardTime} || 'minute' AS INTERVAL)
```

- CAST 사용법 : CAST는 데이터 타입을 변경하는 함수이다.

```sql
-- 숫자 -> 문자열
SELECT CAST(123 AS VARCHAR(10));

-- 문자열 -> 날짜
SELECT CAST('2024-10-10' AS DATE);
```

- 해결
	- $nextTick을 사용

```javascript
this.$nextTick(() => {
	const captchaEl = document.getElementById("captcha00");
	if (captchaEl) {
		captchaEl.focus();
	}
})
```
- $nextTick() : DOM이 업데이트된 후에 실행할 코드를 예약하는 것. DOM이 업데이트된 후에 실행됨.

__🍎 watch 실행 & DOM 랜더링__
1. 데이터 변경 : 컴포넌트의 데이터가 변경됨.
2. watchers : watch 실행.
3. Reactivity 시스템 : Vue의 반응형 시스템이 변경 사항 감지하고, 필요한 경우 DOM 재랜더링
4. Virtual DOM 업데이트 : Vue는 가상 DOM을 사용하여 변경된 내용을 계산하고, 실제 DOM을 최소한으로 업데이트함.

- DOM이 랜더링 된 후 함수를 실행하고 싶으면 $nextTick() 사용.

```javascript
/*
1. userSubInfo가 변경된다.
2. DOM이 업데이트 된다.
3. initSelected() 함수가 실행된다.
*/
watch: {
	'userSubInfo': function() {
		this.$nextTick(() => {
			this.inistSelected();
		})
	}
}
```

- created에선 DOM이 완전히 준비가 안되었기 때문에 직접적인 접근은 어렵다!!!
- 랜더링 이후에 DOM에 접근하려면 mounted에서 호출해야 한다!
