__🍎 Mybais에서 Interval에 변수 사용법__
- 내가 사용하고 싶은 SQL
```sql
SELECT COUNT(*)
FROM 2FACTOR_SEND SEND
WHERE SEND.RESTRICT_DT > NOW() - interval '5minute'
```
- 5minute의 5를 변수로 사용하고 싶었다. 아래처럼 작성하니 오류 발생 ($3 잘못된 syntax라며..)
```sql
SELECT COUNT(*)
FROM 2FACTOR_SEND SEND
WHERE SEND.RESTRICT_DT > NOW() - interval #{standardTime} || 'minute'
```

- cast를 사용해서 해결~
```sql
SELECT COUNT(*)
FROM 2FACTOR_SEND SEND
WHERE SEND.RESTRICT_DT > NOW() - CAST(#{standardTime} || 'minute' AS INTERVAL)
```
