## 소켓에서 필요한 함수
- socket() : 소켓 초기화
- accept() : TCP를 이용한 연결형 응용 프로토콜에서 클라이언트로부터 연결 요청을 받는다는 의미로 서버에서 사용.
- bind() : 포트 연결
- close() : 소켓을 닫는데 사용
- connect() : TCP를 이용한 연결형 프로토콜에서 서버와의 TCP 연결을 위해 클라이언트에서 사용
- listen() : TCP를 이용한 연결형 프로토콜에서 클라이언트로부터 온 요청을 허락한다는 의미로 서버에서 사용.
- recv() : 수신. 소켓으로부터 들어오는 데이터를 받아들임.
- send() : 송신. 소켓을 통해 데이터를 전송


## 서버 소켓 동작 방식
- `socket()` -> `bind()` -> `listen()` -> `accept()` -> `send()` 또는 receive -> `close()`
1. 새 소켓 생성
2. 현재 서버가 위치한 호스트의 주소로 소켓을 연결
3. listen()로 클라이언트로부터 연결을 기다림. 서버는 클라이언트의 요청을 처리하기 위해 무한 대기
4. accept()로 클라이언트로부터 연결 요청이 오면 이를 허락하고 연결함.
5. 필요한 데이터 주고 받음.
6. 더 이상 전송이 없으면 연결을 종료
7. 다른 클라이언트로부터 연결 요청이 오면 4부터 반복

## 클라이언트 소켓 동작 방식
- `socket()` -> `connect()` -> `send()` or receive -> `close()`
1. 새 소켓 생성
2. 서버에게 연결 요청
3. 서버와 연결이 이루어지면 필요한 데이터 주고 받음.
4. 더 이상 전송할 데이터가 없으면 연결을 종료

## Java 소켓 프로그래밍
- java.net.*
- Socket 클래스 : 연결형 클라이언트
- ServerSocket 클래스 : 연결형 서버

- 표준 소켓에서 연결형 클라이언트는 socket()으로 소켓을 생성한 후 서버와의 연결을 connect()로 시도하지만 자바에선 Socket 클래스를 생성하면 바로 서버와의 연결을 시도한다.
- 표준 소켓에선 호스트와 네트워크의 바이트 순서 반환을 위해뗘ㅜㅐㅐ0101@
 htons(), htonl(), ntohs(), ntohl() 등의 함수를 사용하지만, 자바의 Socket 클래스에서는 자동으로 처리된다.
- ServerSocket 클래스의 객체를 생성하면 표준 소켓에서의 listen()과 bind()가 함께 이루어진다.
