## 🔴 대칭키(Symmetric Key) = 비밀키(Secret Key)
- 하나의 Secret Key로 암호화, 복호화를 한다.
- 속도가 빠르다.
- Secret Key 유출 시 보안이 취약하다.
- 대표 알고리즘 : **AES**, DES, 3DES, Blowfish 등
- 주 용도 : 데이터 암호화
- 대칭키의 문제 : Secret Key를 어떻게 관리할까?

### 🟡 예시
- 상황 예시 : A가 B에게 데이터를 전송하는 상황. A와 B가 각각 B의 Secret Key를 가지고 있다고 가정.
  1. A는 데이터를 B의 Secret Key로 암호화하여 전송한다.
  2. 그 데이터를 받은 B는 B의 Secret Key로 복호화한다.

```java
import javax.crypto.Cipher;
import javax.crypto.SecretKey;
import javax.crypto.spec.GCMParameterSpec;
import javax.crypto.spec.SecretKeySpec;
import java.security.SecureRandom;
import java.util.Base64;

public class AesGcmUtil {
  private static final String ALG = "AES/GCM/NoPadding";
  private static final int IV_LENGTH = 12; // 96 bits recommended for GCM
  private static final int TAG_LENGTH_BIT = 128; // authentication tag length

  // AES key bytes must be 16/24/32 bytes (128/192/256 bits)
  public static String encryptBase64(SecretKey key, byte[] plainBytes, byte[] aad) throws Exception {
    
      // 1) 랜덤 IV 생성 : 같은 키로 동일한 IV를 사용하면 보안에 취약하므로 암호화할 때마다 새IV 생성
    byte[] iv = new byte[IV_LENGTH];
    SecureRandom rnd = new SecureRandom();
    rnd.nextBytes(iv);

    // 2) Cipher 초기화 : GCM은 무결성 검증을 함.
    Cipher cipher = Cipher.getInstance(ALG);
    GCMParameterSpec spec = new GCMParameterSpec(TAG_LENGTH_BIT, iv);
    cipher.init(Cipher.ENCRYPT_MODE, key, spec);

    // 3) (옵션) AAD 설정 — 헤더/메타데이터를 인증하려면 사용
    if (aad != null) {
      cipher.updateAAD(aad);
    }

    // 4) 암호화
    byte[] cipherBytes = cipher.doFinal(plainBytes);

    // 5) IV + ciphertext 를 합쳐 Base64로 인코딩
    // => B에서 복호화할 때 IV를 사용해야 하기 때문에 문자를 조합해서 전송함.
    byte[] combined = new byte[iv.length + cipherBytes.length];
    System.arraycopy(iv, 0, combined, 0, iv.length);
    System.arraycopy(cipherBytes, 0, combined, iv.length, cipherBytes.length);

    return Base64.getEncoder().encodeToString(combined);
  }

  public static byte[] decryptBase64(SecretKey key, String base64Combined, byte[] aad) throws Exception {
    byte[] combined = Base64.getDecoder().decode(base64Combined);

    // IV 분리
    byte[] iv = new byte[IV_LENGTH];
    System.arraycopy(combined, 0, iv, 0, IV_LENGTH);

    byte[] cipherBytes = new byte[combined.length - IV_LENGTH];
    System.arraycopy(combined, IV_LENGTH, cipherBytes, 0, cipherBytes.length);

    Cipher cipher = Cipher.getInstance(ALG);
    GCMParameterSpec spec = new GCMParameterSpec(TAG_LENGTH_BIT, iv);
    cipher.init(Cipher.DECRYPT_MODE, key, spec);

    if (aad != null) {
      cipher.updateAAD(aad);
    }

    return cipher.doFinal(cipherBytes); // throws AEADBadTagException if auth fails
  }

  // SecretKey를 Base64 문자열로 주고받는 경우 (복원 방법)
  public static SecretKey secretKeyFromBase64(String base64Key) {
    byte[] keyBytes = Base64.getDecoder().decode(base64Key);
    return new SecretKeySpec(keyBytes, "AES");
  }

  /*＊ 사용 예시 */
  public static void main(String[] args) throws Exception {
    // (예) 키는 이미 A와 B가 공유하고 있다고 가정. (Base64 문자열이라 가정)
    String base64Key = "uLrVj6s0k2Ybq3v1Z0x9hg=="; // 예시(실제는 16/24/32바이트 key 필요)
    SecretKey key = secretKeyFromBase64(base64Key);

    String plain = "민감한 데이터";
    byte[] aad = "request-id:12345".getBytes(); // 선택적 AAD

    // 암호화
    String encrypted = encryptBase64(key, plain.getBytes("UTF-8"), aad);

    // 복호화
    byte[] decrypted = decryptBase64(key, encrypted, aad);
  }
}


```


## 🔴 비대칭키(Asymmetric Key)
- 암호화하는 키, 복호화하는 키가 각각 존재한다. 2개의 키는 public key, private key로 구성된다.
  - public key : 누구나 볼 수 있음.
  - private key : 자신만 알 수 있음.
- 속도가 느리다.
- 키 쌍 구조로 되어 있어 보안성이 높다.
- 대표 알고리즘 : **RSA**, DSA, ECC 등
- 주 용도 : 키 교환, 전자서명, 인증
