## 🔴 대칭키(Symmetric Key) = 비밀키(Secret Key)
- 하나의 Secret Key로 암호화, 복호화를 한다.
- 속도가 빠르다.
- Secret Key 유출 시 보안이 취약하다.
- 대표 알고리즘 : **AES**, DES, 3DES, Blowfish 등
- 주 용도 : 데이터 암호화
- 대칭키의 문제 : Secret Key를 어떻게 관리할까?

### 🟡 예시
- 상황 예시 : A가 B에게 데이터를 전송하는 상황. A와 B가 각각 B의 Secret Key를 가지고 있다고 가정.
  1. A는 데이터를 B의 Secret Key로 암호화하여 전송한다.
  2. 그 데이터를 받은 B는 B의 Secret Key로 복호화한다.


## 🔴 비대칭키(Asymmetric Key)
- 암호화하는 키, 복호화하는 키가 각각 존재한다. 2개의 키는 public key, private key로 구성된다.
  - public key : 누구나 볼 수 있음.
  - private key : 자신만 알 수 있음.
- 속도가 느리다.
- 키 쌍 구조로 되어 있어 보안성이 높다.
- 대표 알고리즘 : **RSA**, DSA, ECC 등
- 주 용도 : 키 교환, 전자서명, 인증
