# 주요 내용 요약
## AI 개발 Workflow
- 탐색(Explore) → 계획(Plan) → 구현(Implement) → 커밋(Commit)으로 이어지는 핵심 사이클을 강조한다.
- 특히 '계획' 단계에 시간을 충분히 투자해야 구현 품질이 높아진다.

### 실전 예제 - URL 단축키 서비스

실제 프로젝트를 선정하고, 브레인스토밍 스킬을 통해 요구사항을 정의하고 설계 문서를 작성하는 과정을 보여줍니다 (0:34:21-1:14:57).
여러 AI 모델(Codex, Gemini 등)을 병렬로 활용하여 코드 리뷰를 수행하는 '토비 팀(Toby Team)' 협업 방식을 시연합니다 (1:18:19).
보안 및 관리: AI가 무분별하게 명령을 실행하지 않도록 퍼미션(Permission)을 설정하고 위험 명령을 차단하는 보안 기법을 다룹니다 (0:47:38, 1:40:47).
이 영상은 AI를 단순한 코드 생성 도구가 아니라, 개발자의 의도에 맞춰 설계를 보완하고 팀 단위 협업까지 확장할 수 있는 **'AI 에이전트 협업 체계'**를 구축하는 데 중점을 두고 있습니다.
