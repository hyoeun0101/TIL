## 🍎 함수 깨끗하게 작성하는 방법

### 1. 작게 만들어라.

- if/else문, while문 등의 내용은 한 줄이어야 한다. 그 한 줄은 함수를 호출하는 부분일 것이다.
- 중첩 구조가 생길만큼 함수가 커져선 안된다.

### 2. 한 가지만 하라.

- 한 가지는 무엇일까? 적당한 추상화. 적당히 추상화가 한 가지여야 한다.
- ex) 페이지가 테스트 페이지인지 확인, 테스트 페이지면 설정 페이지와 해제 페이지 넣기, 페이지를 HTML로 랜더링.
  - 그 문장 하나하나를 다 쪼개라는 소리가 아니다. 저 한 문장을 추상화하여 적당한 추상화 수준을 만들어야 한다. 그 추상화 수준이 함수에는 한 가지여야 한다는 소리다.
- 함수가 한 가지만 하는지 판단하는 방법 : 의미 있는 이름으로 다른 함수를 추출할 수 있다면 그 함수는 여러 작업을 하는 셈이다.

### 3. 함수 당 추상화 수준은 하나로

- 내려가기 규칙
  - 코드는 위에서 아래로 이야기처럼 읽혀야 좋다. 내려가며 읽으면 함수의 추상화는 점점 낮아진다. 즉 내려갈 수록 더 구체적이다.

## 🍎Switch문

- Switch문은 작게 만들기 어렵다. 본질적으로 Switch문은 N가지를 처리한다.

### 다형성 이용하기

```java
public Money calculatePay(Employee e) throws InvalidExeption {
    switch(e.type) {
        case A:
            return calculateA(e);
        case B:
            return calculateB(e);
        case C:
            return calculateC(e);
        default:
            throw new InvalidExeption(e.type)
    }
}
```

- 문제점
  - 새 유형을 추가하면 더 길어진다.
  - 한 가지만 작업하지 않는다. SRP 위반.
  - OCP 위반.
