## 📝 2025-02-17(월)

### 신규기기 알람 초기화 관련 상태값 처리

- 신규기기 2factor, 신규기기 알람 상태값 동기화 필요함.
    
    - 반영 후 처음 접속 시 기기 관리 테이블에 제한여부(Y) 신규기기 전송여부(null) 이 상태임.
    
    - 이 때 Y, Y로 동기화 처리해야함.

|신규기기 2factor|신규기기 알림|상태값 처리|
|---------------|-------------|---|
|ON|OFF|투팩터 인증 진행, 진행 성공하면 테이블 상태값 둘 다 N,N |
|ON|ON|제한여부 N, 알림 대상 N|
|OFF|OFF|처리없음|
|OFF|ON| 알림 대상 N|

<br><br>


|신규기기 2factor|신규기기 알림|디바이스 초기화 방식|
|---------------|-------------|---|
|ON -> OFF|OFF| 제한여부 전체 Y 초기화, 알림대상 전체 Y 초기화|
|ON -> OFF|ON| 제한여부 전체 Y 초기화|
|OFF -> ON|OFF|내꺼 제외 나머지 Y 초기화, 알림대상 내꺼 제외 나머지 Y 초기화|
|OFF -> ON|ON|내꺼 제외 나머지 Y 초기화|
|OFF|ON -> OFF|알림 N 초기화|
|OFF|OFF -> ON|알림은 초기화 없음|
|ON|ON -> OFF|알림은 factor와 동일 상태|
|ON|OFF -> ON|알림은 초기화 없음.|

<br><br>

- 신규기기 알람 null일 때 기본값 Y로 해야함. 운영 반영 후 처음 로그인 접속할 때 제한여부(Y), 알람대상여부(null)인 상태. -> 제한여부가 Y 인 경우 알림대상여부도 Y로 변경해줘야 함.
