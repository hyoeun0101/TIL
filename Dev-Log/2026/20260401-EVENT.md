### 이벤트 응모
- Step1. 참여 선점 — INSERT `EVENTV2_APPLY`
- Step2. 회원 유형 체크 — 신세계포인트 spcom API 호출
- Step3. 미션 실적 체크 — 신세계포인트 authapp API 호출
- Step4. 미션 달성 여부 판정 (달성 조건 수 비교)
- Step5. 참여 결과 UPDATE — UPDATE `EVENTV2_APPLY`
  - 미션 달성 (`applyStatus=0`): `USE_SE_CODE='Y'`
  - 미션 미달성 (`applyStatus=5`): `USE_SE_CODE='Y'` (참여 기록 유지)
  - 그 외 오류: `USE_SE_CODE='N'`

> `EVENTV2_APPLY_REWARD`는 앱에서 INSERT하지 않음. 배치(4단계)에서 INSERT.

| 테이블 | 설명     |  PK / 핵심 컬럼                                                                       |
|--------|--------|-----------------------------------------------------------------------------------|
| `EVENTV2_APPLY`| 이벤트 참여 | PK: `CTMMNY_NO`, `EVENT_NO`, `APPLY_NO` / `MBER_NO`, `USE_SE_CODE`('Y'=유효/'N'=무효) |

## 4. 배치 — 당첨자 보상
> batch - `ShinsegaepointEventWinMberExecController.java`


> 실행 조건: `EVTTY50_WIN_REWARD_DE` = 오늘

- Step1. 대상 이벤트 조회 — SELECT `EVENTV2` (EVENT_TY_SE_CODE IN ('30','50'), 오늘 = WIN_REWARD_DE)
- Step2. 미처리 당첨 회원 조회 — SELECT `EVENTV2_WIN_MBER_UPLOAD` (BATCH_EXEC_YN='N', 페이징)
- Step3. 참여번호 확보 — SELECT `EVENTV2_APPLY` (MBER_NO 기준 최근 APPLY_NO 조회)
- Step4. 처리 시작 표시 — UPDATE `EVENTV2_WIN_MBER_UPLOAD` SET `BATCH_EXEC_YN='Y'`, `APPLY_NO`=조회값
- Step5. 신세계포인트 API로 보상 지급
- Step6. 보상 내역 기록 — INSERT `EVENTV2_APPLY_REWARD`
- Step7. 처리 결과 기록
  - 성공: UPDATE `EVENTV2_WIN_MBER_UPLOAD` SET `BATCH_EXEC_SUCESS_YN='Y'`
  - 실패: UPDATE `EVENTV2_WIN_MBER_UPLOAD` SET `BATCH_EXEC_SUCESS_YN='N'`, `REWARD_EXEC_RESULT_MSG`=오류내용

| 테이블 | PK / 핵심 컬럼 |
|--------|----------------|
| `EVENTV2_WIN_MBER_UPLOAD` | `APPLY_NO`, `BATCH_EXEC_YN`, `BATCH_EXEC_SUCESS_YN`, `REWARD_EXEC_RESULT_MSG` |
| `EVENTV2_APPLY_REWARD` | PK: `CTMMNY_NO`, `EVENT_NO`, `REWARD_NO` / `APPLY_NO`, `MBER_NO`, `REWARD_COND_SN`, `REWARD_PAY_YN`, `REWARD_POINT_AMT` |

> 실패건(`BATCH_EXEC_SUCESS_YN='N'`)은 자동 재처리 없음. 운영자 수동 처리 필요.
