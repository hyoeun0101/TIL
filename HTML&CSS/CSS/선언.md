- 내장 방식
- 링크 방식-병렬방식
- 인라인 방식<div style="color:red;">
- @import 방식-직렬방식

<link rel="stylesheet" href="./css/main.css">    
[main.css]    
```html
@import url("./box.css");
div{
    color:red;
}
```
[box.css]
```html
.box{
    background-color:red;
}
```
: CSS 문서 안에서 또 다른 CSS문서를 가져와 연결하는 방식, 직렬로 연결되있음. main.css에서 임포트가 실행되기 전까지는 box.css와 연결되어 있지 않음. 즉 연결이 지연됨.
