# 상속

`글자`와 `문자` 관련 속성들은 상속된다.  
font-style(글자 기울기), font-weight(글자 두께), font-size(글자 크기), line-height(줄 높이), font-family(폰트), color(글자 색상), text-align(정렬) 등

### 강제 상속

```html
<div class="parent">
  <div class="child"></div>
</div>
```

inherit : 부모의 것 강제상속.

```css
.parent {
  width: 400px;
  height: 200px;
  background-color:red;
}
.child {
  width: 200px;
  height: inherit;//부모의 것 강제 상속
  background-color:orange;
}
```
