# margin

- 0(default) : 외부 여백없음
- auto : 브라우저가 여백 계산, 가운데 정렬에 활용!
- 단위(px,em,vw 등)
- % : 거의 안씀. 부모 요소의 가로 너비에 대한 비율로 지정
- 음수이면 겹친다.

`margin : 10px 10px 10px 10px`  
top-rigth-bottom-left

`margin : 10px 10px`  
top,bottom - left, right

`margin : 10px 20px 30px`  
top - left,rigth - bottom
