- px: 픽셀
- %: 상대적 백분율
- em : 요소의 글꼴 크기
- rem : 루트 요소의 글꼴 크기
- vw : 뷰포트 가로 너비의 백분율
- vh : 뷰포트 세로 너비의 백분율

## em , rem

10em = 10 \* 16(font-size) = 160px  
기본적인 font-size는 16px이다.  
font-size는 자동 상속된다.

```html
.parent{ font-size:10px; } .child{ width:50em; }
```

자식은 500px.

```html
html{ font-size:16px; } .parent{ font-size:10px; } .child{ width:50rem; }
```

rem은 최상위 부모 요소를 상속받기 때문에 child의 width는 800px가 된다. rem은 전체적으로 크기를 조절할 때 편리하다.
