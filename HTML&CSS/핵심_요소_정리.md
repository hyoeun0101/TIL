# 인라인 요소 & 블록 요소

![img](/image/inline_block.png)
|요소|특징|
|------|-----|
|inline|보통 글자 요소들이 inline임. 예외적으로 img 태그있음. 가로 세로 여백 조절 불가능|
|block|가로,세로(width, height), margin, padding으로 조절 가능|

### <div> - block

특별한 의미가 없는 구분을 위한 요소.

### <h1>~<h6> - block

제목을 의미하는 요소. 숫자 작을수록 더 중요한 제목. h2~h4 많이 씀. 페이지의 대주제는 h1

### <p> - block

문장을 의미하는 요소.

### <img> - inline

이미지를 삽입하는 요소.

```
<img scr="경로" alt="이미지의 이름">
```

위처럼 써야함. 이미지 깨지면 이름 출력.

### <ul> ,<li> - block

- ul : 순서 필요없는 목록. ul태그의 자식으로 li 한 개이상 작성해야함.
- li : 목록 내 각 항목

```html
<ul>
  <li>사과</li>
  <li>딸기</li>
  <li>수박</li>
  <li>사과</li>
</ul>
```

### <a> - inline

페이지 이동

```html
<a href="https://www.naver.com">NAVER</a>
<a href="https://www.google.com" target="_blank">GOOGLE</a>
```

NAVER GOOGLE 한라인에 출력됨.  
target="\_blank" 쓰면 새 탭으로 열림

### <span> - inline

```html
<span style="color:red;">동해물</span>과 백두산이 마르고 닳도록
```

<span style="color:red;">동해물</span>과 백두산이 마르고 닳도록

### <br/> -inline

줄바꿈 요소. 코드 상에서 Enter는 줄바꿈 안되고 <br>써야함~

### <input> - inline-block

사용자가 데이터를 입력하는 요소.  
수평으로 쌓이는 inline적인 특징. 가로세로, 여백 설정할 수 있는 block의 특징 가지고있음.

```html
<input type="text" value="값" placeholder="이름을 입력하세요" disabled />
```

- value: 미리 값이 들어가 있음.
- placeholder: 값 입력 힌트주는 역할.
- disabled: 입력 못하게 비활성화시킴.

### 체크박스

```html
<label> <input type="checkbox" />Apple </label>
<label> <input type="checkbox" checked />Banana </label>
```

체크 여부 입력받음.  
checked: 미리 체크해둠.

### 라디오

```html
<label> <input type="radio" name="fruits" />Apple </label>
<label> <input type="radio" name="fruits" />Banana </label>
```

1개만 선택 가능. name으로 같은 그룹으로 묶음. name 다르면 같은 그룹이 아님.

### label - inline

```html
<label> <input type="checkbox" />Banana </label>
```

[] Banana  
checkbox와 Banana 이름을 하나로 묶음. checkbox 또는 Banana 이름 클릭하면 체크됨.

### table - 테이블 요소

행(row)과 열(column)의 집합

```html
<table>
  //행 하나
  <tr>
    <td>A</td>
    <td>B</td>
  </tr>
  //행 둘
  <tr>
    <td>C</td>
    <td>D</td>
  </tr>
</table>
```

| A   | B   |
| --- | --- |
| C   | D   |

- tr : table row
- td : table data.

```html
<table>
  //행 하나
  <tr>
    <td>A</td>
    <td>B</td>
    <td>B</td>
  </tr>
  //행 둘
  <tr>
    <td>C</td>
    <td colspan="2">D</td>
  </tr>
</table>
```

| A   | B   | B   |
| --- | --- | --- |
| C   | D   |
