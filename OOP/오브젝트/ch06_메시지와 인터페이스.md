## 🍎 협력과 메시지
- 메시지 : isSatisfiedBy(screening)
- 메시지 전송 : condition.isSatisfiedBy(screening)
- 오퍼레이션 : 메시지의 추상화
- 메서드 : 메시지에 응답하기 위해 실행되는 코드 블록. 오퍼레이션의 구현
- 퍼블릭 인터페이스 : 메시지의 묶음
- 시그니처 : 오퍼레이션이나 메서드의 명세

## 🍎 인터페이스와 설계 품질
- 좋은 인터페이스란? 최소한의 인터페이스, 추상적인 인터페이스
- 다음과 같이 설계하라.
### 1. 디미터 법칙
- 하나의 도트만 사용하라.
```java
//디미터 법칙 위반
screening.getMovie().getDiscountConditions();
```
- 인스턴스 변수의 객체, 메서드의 인자로 받은 객체나 메서드 내에서 만든 객체에게만 메시지를 전송하라.
### 2. 묻지 말고 시켜라.
- 상태를 묻지말고, 그저 행동을 시켜라.
