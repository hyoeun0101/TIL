## 1. 셸 개요
### Shell
- 명령어 해석기. 사용자와 커널 사이에서 명령어를 해석하여 처리한다.
- 반복적으로 수행되는 작업을 셸 스크립트로 작성하여 처리한다.
- 텍스트 모드로 로그인을 하면 기본 셸이 주어짐.

### 셸의 종류
- 많은 리눅스 배포판에서 Bash를 기본 셸로 사용한다.
- 명령 프롬프트로 일반 사용자는 $, root 사용자는 #을 사용함.

### Bash 셸
- 실행 명령은 `/bin/bash`

### 셸 선택하기
- 기본 셸 변경하기 : `chsh -s /bin/sh`
- 셸 종료 : `exit` or `Ctrl + d`
- 로그인 셸과 비로그인 셸 구분하기
    - `logout` 명령은 로그인 셸에서만 가능.
    - `Ctrl + Alt + (F1~F6)`으로 가상 콘솔 사용할 수 있음.
    - 셸 프롬프트에서 셸 프로그램을 실행하면 서브 셸이 실행됨.

## 🍎 셸 명령어
- 관리자 명령 or 일반 사용자 명령이 있음.
- 환경변수 PATH에 설정된 경로 중 실행 파일이 존재하면 명령의 이름만으로 실행 가능
    - 아니면 해당 실행 파일의 절대 경로를 사용해야 함.
    - 현재 디렉토리(.)는 보통 PATH에 포함되어 있지 않음. 따리서 현재 디렉토리에 있는 실행 파일 실행하려면 ./ 이렇게 작성해야 함!
    - echo $PATH로 저장된 경로 확인할 수 있음.
### chsh 명령
- 기본 셸 변경
```shell
chsh [options] [username]
chsh -s /bin/sh khe
chsh --shell=/bin/bash khe
```
- khe 사용자의 기본 디렉토리를 /bin/sh로 변경


### alias 명령
```shell
alias
alias la='ls -A'
alias rm='rm -i'

unalias rm
```
- 계속 유지하려면 셸의 환경 설정 파일에 기록해 두어야 함.

### type 명령
- 명령이 어떻게 해석되는지 알려 주는 명령
```
type cd
type -a ls
```
### which 명령
- 실행 프로그램을 환경변수 PATH를 기초로 찾아 경로를 출력
```
which rm
```
### man 명령
- 메뉴얼 페이지를 보여주는 명령
```shell
man passwd
man 5 passwd
```
- 1: 사용자 명령
- 2: 커널의 시스템 호출
- 3: C 라이브러리 함수
- 4: 디바이스 드라이버 정보
- 5: 시스템의 설정 파일
- 6: 게임
- 7: 파일 포맷, 인코딩 등
- 8: 시스템 관리 명령

### history
```
history
history 10
```
- !! : 직전 명령 실행
- !숫자 : 해당 숫자 명령 실행 ex) !3
- !문자 : 지정된 문자열로 시작하는 최근 명령 실행 ex) !d
