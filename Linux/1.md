### 파티션
- 하드디스크를 논리적으로 나눈 구역. 파티션 별로 파일 시스템을 만들 수 있음
- 윈도우에서는 각 파티션마다 각각의 드라이브로 지정 -> C 드라이브, D드라이브.
    - 각 드라이브마다 루트 디렉터리 존재. C:/, D:/
- 리눅스는 오직 __1개의 루트 디렉터리(/)__ 를 가짐.
    - 파티션은 루트 파일 시스템의 특정 디렉터리에 마운트시켜야함.
    - 리눅스는 하드디스크, 주변 장치를 __파일__ 로 취급

### 장치이름
- /dev/hd0 : IDE 디스크. 이름에 hd 붙임.
- /dev/sd0 : SCSI 디스크. 이름에 sd를 붙임.
- /dev/sr0 : CD 또는 DVD.

### 표준 디렉터리


|디렉터리 표시  |의미|
|-----------------|---|
|/       |루트 디렉터리|
|/bin|바이너리 디렉터리. 기본적인 명령의 실행 파일을 포함.|
|/sbin|바이너리 디렉터리. 부팅 과정, 시스템 관리에 필요한 명령의 실행 파일을 포함.|
|/boot|부트 디렉터리. 커널 이미지와 부트 로더의 설정 파일을 포함|
|/dev|디바이스 디렉터리. 장치를 접근하는데 사용되는 `디바이스 파일`이 위치함|
|/etc|시스템 설정 파일 디렉터리. 시스템의 중요한 환경 설정 파일이 위치.|
|/home|사용자 계정 디렉터리. 사용자의 홈 디렉터리는 해당 사용자만 사용할 수 있는 공간.|
|/lib|공유 라이브러리 디렉터리. 프로그램들이 사용하는 시스템 라이브러리 파일이 위치함.|
|/media|미디어 디렉터리. 이동식 저장 장치가 마운트될 때 마운트 지점을 제공.|
|/proc|커널이 사용하는 가상의 파일 시스템|
|/root|루트 계정의 홈 디렉터리|
|/usr|사용자 디렉터리, /usr/bin, /usr/lib|
|/var|가변 자료 저장 디렉터리. 시스템 운영 중 필요한 가변 자료가 저장되는 디렉터리. 시스템 작동 로그, 인쇄용 스풀 영역, 사용자 메일박스 등|


### 셸(Shell)
- 명령어 해석기. 사용자와 커널 사이에서 명령어를 해석하여 처리.
- 반복 작업을 셸 스크립트로 작성하여 실행할 수 있음. 셸이 셸 스크립트 파일을 읽어 처리함.
- `세미콜론(;)`을 사용하면 한 라인에 여러 명령 입력 가능!

<br>

- 셀의 종류 : 기본적으로 Bash 셸 이용. 
    - 명령 프롬프트로 일반사용자는 $, root 사용자는 #을 사용.
    - 셸의 종류에 따라 에일리어스 설정, 초기화 파일, 셸 스크립트 작성법, 명령 행 편집 기능 등에 차이가 있음.   

```
-- 사용 중인 셸 확인하기
/etc/passwd 파일에서 확인 가능.


-- 기본 셸 변경하기
chsh -s /bin/sh

```

- 터미널 창을 '대화형 셸'이라고도 함. = `비로그인 셸`
- 텍스트 모드로 로그인하면 `로그인 셸`이 주어짐. logout명령은 로그인 셸에서만 가능.
- `Ctrl` + `Alt` + `F1~F6` : 가상 콘솔 주어짐. F2는 우리가 사용하는 일반 GNOME 데스트톱으로 이동.

### 셸 명령
- 관리자 명령 or 사용자 명령이 있음.

- 환경변수 PATH에 설정된 경로 중 실행 파일이 존재하면 명령의 이름으로만 실행 가능.
- 현재 디렉토리(.)는 보통 PATH에 포함되어 있지 않음. 그래서 ./ 이렇게 작성함.

```shell
-- 저장된 경로 확인
echo $PATH
```

```shell
######## alias : 단축 명령 만들기 ########
alias la='ls -A'
alias rm='rm -i'

# 단축 명령 해제
unalias rm
```
-> 계속 유지하려면 셸의 환경 설정 파일에 기록해 두어야 함.

```shell
######## type : 명령이 어떻게 해석되는지 알려줌 ########

# cd는 내장 명령이다라고 알려줌
type cd

# 모든 정보 출력.
type -a ls
```

```shell
######## which : 실행 프로그램을 환경변수 PATH를 기초로 찾아 경로를 출력 ########

which rm
```

```shell
######## man : 메뉴얼 페이지를 보여줌 ########

man passwd

man 5 passwd
```

```shell
######## history : 이전에 수행했던 명령 행의 목록을 불러옴 ########

history

# 10 행의 명령어 불러옴
history 10

# 직전 명령 실행
!!

# 히스토리 10행 명령 실행
!10

# 해당 문자열로 시작하는 최근 명령 실행
!string

```

## 특수문자

|문자|의미|
|------|-----|
|백슬래시(\)|명령 행 분리할 때 사용|
|틸드(~)|~또는 ~username은 사용자의 홈 디렉터리를 의미|
|도트(.)|현재 작업 디렉터리 표시|
|더블도트(..)|현재 디렉터리의 부모 디렉터리|
|파운드(#)|주석 처리|
|달러($)|`$변수`는 변수의 값을 추출|
|앰퍼샌드(&)|`명령&`은 명령을 백그라운드로 실행시킴. 즉 바로 명령 실행|
|애스터리스크(*)|파일 이름에서 사용: 0개 이상의 임의 문자열과 대응|
|물음표(?)|파일 이름에서 사용: 1개 문자와 대응|
| 파이프(\|) |앞 명령의 출력을 다음 명령의 입력으로 연결|
|< 또는 >|파일로부터 입력받을 때 or 출력할 때 사용|
|>>|표준 출력을 파일의 끝에 덧붙일 때 사용|
|!|명령 히스토리 기능 이용할 때 사용|

```shell
# | 예시
cat /etc/passwd | sort | more

# 해당 파일을 명령의 입력으로 
sort < /etc/passwd

# 명령 결과를 해당 파일로 출력
grep typedef /usr/include/* > typedef.out

# 명령 수행 중 표준 오류를 해당 파일로 출력
ls 2>> error.txt

```
- 명령 0< 파일 : 0은 생략. 입력을 의미
- 명령 1> 파일 : 1은 생략. 출력을 의미
- 명령 2> 파일 : 오류를 출력

### 명령 치환
- 명령 수행할 때, 명령의 인수로서 다른 명령의 결과를 사용
- `$(command)` 또는 \`command`

```shell
# which passwd의 결과를 인수로 사용
ls -l $(which passwd)

echo "There are $(ls | wc -w) files in this directory."
```

### 인용 부호

```shell

$ echo "$(date)"
> 2024. 10. 10 . (목) 01:25:47 KST

# \는 특수 문자 의미 제거
$ echo "\$(date)"
> $(date)

# ''은 특수 문자 의미 제거
$ echo 'Today is $(date)'
> Today is $(date)
```

### 수식과 변수 사용
- 수식 사용하기 : `$[수식]` 또는 `$((수식))`
- 변수 사용하기 : `$변수`
```shell
$ echo "I am $[2023-1979] years old."
> I am 44 years old.

$ echo BASH
> BASH

$ echo $BASH
> /usr/bin/bash

```

### 셸 변수와 환경 변수
- 문자열 정보를 저장함.
- 셸 변수 = 지역 변수. 변수가 정의된 셸에서만 사용 가능.
- 환경 변수 = 전역 변수.
    - 서브 셸로도 전달됨.
    - 변수명으로 대문자 사용.
    - 터미널 창을 열어 셸을 시작하면 이미 많은 환경 변수가 설정되어 있음.

```shell
# 셸 변수 선언 및 출력
$ NAME="KHE"
$ echo $NAME
> KHE

# 시스템의 모든 환경 변수 출력
$ printenv

# 현재 셸의 모든 환경 변수 출력
$ export -p

# 변수 설정 & 환경 변수 만들기
$ FOO=bar; export FOO
# 또는
$ export FOO=bar

# 서브 셸로 이동
$ sh

# 변수 삭제
$ unset FOO
```

|환경 변수|내용|
|--------|----|
|HISTSIZE|1개 셸에서 저장되는 history 목록 최대 개수. 기본값은 1000|
|HOME|홈 디렉터리|
|MAIL|사용자의 메일박스에 해당하는 파일 ex) /var/spool/mail/username|
|PATH|명령 수행할 때 실행 파일을 찾기 위한 디렉터리 목록|
|PS1|셸 프롬프트를 표시하기 위한 문자열|
|SHELL|사용 중인 기본 셸|
|PWD|현재 작업 디렉터리|
|USER|현재 사용자 계정|

```shell
$ echo $PS1
> [\u@\h \W]\$

```

__환경 변수는 언제 어떻게 만들어지나?__
- 로그인할 때 or 셸을 시작할 때 자동으로 실행되는 명령을 저장한 파일이 존재.

<br>

__로그인 할 때 실행되는 파일__

- `/etc/profile` : 모든 사용자에게 적용. PATH, MAIL, HISTSIZE 등의 환경변수 설정됨.
- `~/.bash_profile` : 개별 사용자에게 적용. (.으로 시작하는 건 숨김 파일을 의미)

<br>

__셸 시작할 때 실행되는 파일__
- `~/.bashrc` : 셸 시작할 때마다 실행. 개별 사용자에게 

|기호|파일|실행 시기|적용 대상|설명|
|---|-----|---------|---------|---|
|A|/etc/profile|로그인 할 때 실행|모든 사용자에게 적용|PATH, MAIL, HISTSIZE 등의 환경변수 설정됨.|
|B|~/.bash_profile|로그인 할 때 실행|개별 사용자에게 적용|내부에서 ~/.bashrc 실행|
|C|~/.bashrc|셸 시작할 때마다 실행|개별 사용자에게 적용|내부에서 /etc/bashrc 실행|
|D|/etc/bashrc|셸 시작할 때마다 실행|모든 사용자에게 적용|PS1 설정, alias 설정, umask를 사용한 접근권한의 초기값 등 설정
|C|~/.bash_logout|X|X|로그아웃 수행할 때 실행|

<br>

- 로그인하면 실행되는 파일 순서 : A -> B -> D -> C
- 셸 시작하면 실행되는 파일 순서 : D -> C
