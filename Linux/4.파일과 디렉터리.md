## 🍎 파일 시스템 탐색
- 파일 시스템? 운영체제가 디스크(파티션) 상에 파일을 구성하는 방식
- 리눅스는 전체 파일 시스템을 1개의 트리 구조로 관리. (1개의 루트 디렉터리만 존재)

### ls
- ls 디렉터리 : 디렉터리에 존재하는 파일, 서브 디렉터리 정보 출력
- ls 파일 : 파일의 정보 출력
```shell
$ ls .
> 모든 파일 출력
$ ls -l date.txt
```
__ls 옵션__

|짧은 옵션|긴 옵션|설명|
|--------|-------|----|
|-a|--all|모든 파일 보여줌. 점(.)으로 숨긴 파일도.|
|-d|--directory|디렉터리 자제체 대한 정보 보여줌.|
|-F|--classify|우측에 파일 종류를 알려주는 문자를 붙임. 실행 파일은 *, 디렉터리는 /, 심볼릭 링크는 @|
|-l|--format=long|긴 포맷으로 결과를 보여줌|
|-R|--recursive|재귀적으로 수행되는데 서브 디렉터리 내용도 나열|
|-S|--sort=size|파일의 크기 순서대로 보여줌|
|-t|--sort=time|최종 수정 시간 순으로 보여줌|


### 파일의 종류
- 정규 파일 : 일반적인 대부분 파일. 데이터를 저장하는데 주로 사용. 실행 파일, 이미지 파일은 바이너리로 저장되어 바이너리 파일이라고 함.

- 디렉터리 : 디렉터리도 파일로 취급.

- 심볼릭 링크 : 윈도우의 바로가기와 비슷. 절대 경로 또는 상대 경로로 원본 파일을 가르키는 링크.

- 장치 파일 : 프린터, 키보드, 하드디스크 등 각종 장치를 파일로 취급. 블록 디바이스 파일과 문자 디바이스 파일로 구분.

```shell
# 파일 종류를 알려주는 명령
$ file /dev/sda1

# 절대 경로 방식으로 현재 작업 디렉터리를 알려줌.
$ pwd

# 디렉터리 이동(절대 경로)
$ cd /usr/bin

# 디렉터리 이동(상대 경로)
$ cd subdir1; cd ../dir1

# 홈 디렉터리로 이동
$ cd
```

## 🍎 파일 관리
### mkdir - 디렉터리 생성
- 우선적으로 디렉터리 생성 권한 있어야 함.
- `-p (--parent)` : 상위 디렉터리도 만듦.
- `-m` : 디렉터리 생성 & 접근권한 설정

```shell
# 디렉터리 생성
$ mkdir dir1;

# -p (--parent)
$ mkdir -p backup/java

$ mkdir -m 755 dir1
```
### rmdir - 디렉터리 삭제
- 비어있는 디렉터리만 삭제 가능.
- 무조건 삭제하려면 `rm -r dir1`, `rm -rf dir1` 사용 (주의 필요)
- `-p` : 비어있는 디렉터리 삭제 & 부모 디렉터리도 비어있으면 같이 삭제
```shell
# dir2를 삭제하고 dir1이 비어있다면 dir1도 삭제
$ rmdir -p dir1/dir2
```

### cp - 파일, 디렉터리 복사

```shell
# file1이 원본, file2 복사본
$ cp file1 file2

# file2가 존재하면 덮어쓰기 수행
$ cp -i file1 file2

# 여러 파일들을 dir1에 복사
$ cp -i files dir1

# 디렉터리를 재귀적으로 복사. dir2가 존재하면 그곳에 dir1 복사
$ cp -r [options] dir1 dir2
```


### mv - 파일, 디렉터리 이름 변경 or 이동

```shell
# file1을 file2로 이름 변경. file2이 존재하면 덮어쓰기
$ mv file1 file2

# dir1 이름을 dir2로. dir2가 존재하면 dir1이 dir2의 서브 디렉터리로 이동
$ mv dir1 dir2

# 여러 파일을 diretory로 이동
$ mv [options] file1 file2 directory

```


### rm - 파일 삭제
- `alias rm='rm -i'`로 설정해서 사용해라~ 삭제하면 복구 못하니...
- `-r` : 디렉터리를 통째로 삭제
- `-i` : 삭제 전에 물어봄
- `-f` : 강제 삭제

```shell
$ rm [options] files
```

## 🍎 접근권한
### 파일 접근 권한
- 소유자(u), 그룹(g), 기타(o)
    - 읽기(r)
    - 쓰기(w)
    - 실행(x)

```shell
$ ls -l 
> drwxr-xr-x. 2 khe khe 6 10월 29 12:33 test.txt
```
- 맨앞 : 파일 종류 (-: 일반파일)
- `rwx` : 소유자 권한
- `r-x` : 그룹 권한
- `r-x` : 기타 사용자 권한
- `khe` : 소유자
- `khe` : 그룹

### 디렉터리 접근 권한

- 읽기(r) : ls dir1 가능.
- 디렉터리를 자유롭게 사용하려면 rwx 권한 모두 가져야 함. 적어도 rx는 있어야 `ls -l` 명령 가능

### chmod - 접근 권한 변경
- 8진수 모드 : r은 4, w는 2, x는 1

```shell
# file1에 소유자는 rwx, 그룹은 r-x, 기타는 --x
$ chmod [options] 751 file1
```

- 기호 모드 : ugoa는 user, group, other, all을 의미.

```shell
# 사용자에게 실행 권한 추가
$ chmod u+x file1

# 사용자-> rwx, 그룹-> rx
$ chmod u=rwx,g=rx,o=x file1
```

### umask - 파일, 디렉터리 접근권한의 기본값 설정 or 출력
- 보통 /etc/bashrc에 설정되어 있음.


```shell
$ umask [-S] [mask]
```
- mask 예시) 마스크 값이 002라는 건 --- --- -w-를 의미. (w를 가려라.)
    - 즉 기타 사용자에게 쓰기 권한 부여하지 않겠다는 것.
    - 마스크 값이 002라는 건 디렉터리에 775 접근권한을 부여한다는 의미.
    - 마스크 값이 002라는 건 파일의 경우 기본적으로 실행 권한은 부여되지 않으며 따라서 접근권한은 664가 됨.

- `touch file1` 명령 : 파일의 접근/수정 시간을 현재 시간으로 변경, 파일이 존재하지 않으면 파일 생성.

<br>

### chown - root 사용자가 파일, 디렉터리의 소유자(or 그룹)를 변경

- 기본적으로 파일의 소유자는 파일을 생성한 사람. 소유 그룹은 그 사람의 그룹.

```shell
# file1의 소유자 변경
$ chown [options] newowner file1

```
- `소유자.그룹` 또는 `소유자:그룹` : 소유자 생략되면 그룹
