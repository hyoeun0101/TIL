## 1. 유닉스와 리눅스
### 유닉스의 특징
- 다중 사용자, 다중 작업을 지원하는 신뢰성 높은 운영체제

- 리눅스는 UNIX의 무료 공개 버전

## 2. 리눅스 개요
- 다중 사용자와 다중 작업을 지원
- 뛰어난 이식성을 제공
- 모듈화되어 있어 업그레이트, 업데이트가 용이
- 오픈소스
- CUI(command 사용)와 GUI를 지원
- 여러 종류의 파일 시스템을 지원
- 효율적 하드웨어 활용

## 3. 오픈소스와 라이선스

### 다양한 오픈소스 소프트웨어 라이선스 
- GPL, LGPL, MPL
    - 기본적으로 소스코드 공개해야함.
    - LGPL : 주로 오픈소스 라이브러리에 적용됨.
    - MPL : MPL 코드를 포함하지 않은 파일은 공개 의무 없음.

- BSD, Apache, MIT 라이선스
     - 배포 시 소스코드 비공개 가능.

### GPL
- 자유롭게 사용, 복제, 배포
- 수정하여 배포하는 겨우 소스코드를 공개해야함.


## 4. 리눅스 배포판

### 주요 리눅스 배포판
- Debian 계열 : Dedian, Ubuntu
- Slacksware 계열 : Slackware, SUSE
- Red Hat 계열 : Redhat, Fedora, CentOS, Rocky Linux
