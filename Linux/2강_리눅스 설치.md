## 2. 저장 장치 이름과 표준 디렉터리
### 파티션
- 하드디스크를 논리적으로 나눈 구역. 파티션 별로 파일 시스템을 만들 수 있음.
- 윈도우에서는 각 파티션마다 각각의 드라이브로 지정.
    - C:\, D:\ 드라이브마다 루트 디렉터리가 있음.
- 리눅스에서는 오직 1개의 루트 디렉터리(/)만 가짐. 리눅스는 하드디스크나 주변 장치를 파일로 취급.
    - 저장 장치를 사용하려면 해당 저장 장치 이름을 루트 파일 시스템의 특정 디렉터리에 마운트시켜야함. 장치 이름 /dev/sdb1를 /home에 부착!

## 장치 이름

### 리눅스 표준 디렉터리
- `/` 루트 디렉터리 : 모든 파일과 디렉터리의 최상위 디렉터리
- `/bin`, `/sbin` 바이너리 디렉터리 
    - /bin: 기본적인 명령의 실행 파일을 가짐.
    - /sbin : 부팅 과정이나 시스템 관리에 필요한 명령의 실행 파일을 가짐.
- `/boot` 부트 디렉터리 : 커널 이미지와 부트 로더의 설정 파일을 가짐.
- `/dev` 디바이스 디렉터리 : 장치를 접근하는데 사용되는 디바이스 파일을 가짐.
- `/etc` 시스템 설정 파일 디렉터리 : 시스템의 환경 설정 파일을 가짐.
- `/home` 사용자 계정 디렉터리 : 사용자 계정의 홈 디텍러리가 만들어짐. /home/khe
    - 홈 디렉토리는 해당 사용자만 사용할 수 있는 독립적인 공간
- `/lib` 라이브러리 디렉터리 : 프로그램이 사용하는 시스템 라이브러리 파일 가짐.
- `/media` 미디어 디렉터리 : 이동식 저장 장치가 마운트될 때 마운트 시점을 제공
- `/proc` 시스템 정보 디렉터리 : 커널이 사용하는 가상의 파일 시스템
- `/root` 루트 계정의 디렉터리 : root 계정의 홈 디렉터리
- `/usr` 사용자 디렉터리
- `/var` 가변 자료 저장 디렉터리
