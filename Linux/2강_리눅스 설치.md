
## 2. 저장 장치 이름과 표준 디렉터리
### 파티션
- 하드디스크를 논리적으로 나눈 구역. 파티션 별로 파일 시스템을 만들 수 있음.
- 윈도우에서는 각 파티션마다 각각의 드라이브로 지정.
    - C:\, D:\ 드라이브마다 루트 디렉터리가 있음.
- 리눅스에서는 오직 1개의 루트 디렉터리(/)만 가짐. 리눅스는 하드디스크나 주변 장치를 파일로 취급.
    - 저장 장치를 사용하려면 해당 저장 장치 이름을 루트 파일 시스템의 특정 디렉터리에 마운트시켜야함. 장치 이름 /dev/sdb1를 /home에 부착!
