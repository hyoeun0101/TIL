
- @EnableWebSecurity : 해당 스프링 시큐리티 필터를 필터체인에 등록
- WebSecuityConfigurerAdapter : 시큐리티 Config, configure 메서드 오버라이딩.
    - url에 권한을 설정할 수 있음.
```java
@Configuration
@EnableWebSecurity
public class SecurityConfig extends WebSecurityConfigurerAdapter{
    @Override
    public void configure(HttpSecurity http) throws Exception {
        http.csrf().disable();
        http.authorizeRequests()
            .antMatchers("/user.**").access("hasRole('ROLE_ADMIN') or hasRole('ROLE_MANAGER')")
            .antyRequest().permitAll()
            .and()
            .formLogin()
            .loginPage("/loginForm")
            .loginProcessingUrl("/login") //login 주소가 호출되면 시큐리티가 낚아채서 로그인을 진행. 즉 /login  
            .defaultSuccessUrl("/");
    }

    @Bean
    public BCryptPasswordEncoder encodePwd() {
        return new BCryptPasswordEncoder();
    }
}
```
