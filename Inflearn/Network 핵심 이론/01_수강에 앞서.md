### 🔴 Layer와 Layered 구조

- `구성 요소`들 간의 `관계`를 표현하기 위해 `도식화`를 함.

- 간단히 말하자면 구성 요소와 관계를 정의하는 게 설계다.

- OSI 7 layer를 보면 위에서부터 아래로 블록 단위를 도식화한다. => Layered 형태

- Layered의 형태는 기본적으로 어떤 행위, 기능에 대해 서로 의존적임을 의미한다. 

- 단순 의존이 아닌 존립하는 경우도 있다. 4계층은 3계층이 있어야 존재하는 관계를 존립이라 표현한다.


### 🔴 User Mode와 Kernel Mode

- 컴퓨터
    - S/W
        - User Mode - Chrome
        - Kernel Mode - TIP/IP

    - H/W
        - NIC (Network Interface Card) = LAN

  ![Alt text](/image/osi.png)

- L1 (물리계층) : NIC (= 하드웨어)

- L2 (데이터링크) : Driver를 포함한 S/W와 H/W 겹침

- L3 (네트워크) : IP (커널)

- L4 (트랜스포트) : TIP (커널)

- L5 (세션) : 여기서부터 User 모드.

- L6 (프레젠테이션)

- L7 (응용) : 크롬

    - TIC/IP를 추상화 시킨 인터페이스를 Socket이라 부른다.

    - 어떤 Process가 어떤 Socket을 열었다.
