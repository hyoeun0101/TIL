## 필요한 사전 지식
- 1byte = 8bit
- 논리연산 가능, Mask 연산
- 2진수를 16진수로 변환하기
- 1024MB = 1GB
- 운영체제는 User mode와 Kernel Mode가 존재한다.
    - User Mode는 어플리케이션, Kernel Mode는 OS.
- Buffer : 실행할 프로세스를 쌓아두는 메모리 공간. 일정량이 다 쌓이면 처리한다. 처리하는 걸 Buffering이라고 함.

- 구성 요소와 관계를 정의하는 게 설계다.(간단히 말하자면)
