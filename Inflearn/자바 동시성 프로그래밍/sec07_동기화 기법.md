## Semaphore (세마포어)
- 신호전달 메커니즘 동기화 도구이다.
- 정수형 변수 S, 원자적 함수 P, V로 구성된다.
- java.util.concurrent 패키지에 세마포어 클래스 제공함.

### 세마포어 작동방식
- S : 정수형 변수. 공유 자원 개수(S)만큼 스레드의 접근이 허용됨.
- P : S가 1 감소(S--). 임계영역 사용 가능한지 판단. wait 연산
- V : S가 1 증가(S++). 대기 중인 프로세스를 깨우는 신호로 signal 연산.
- S가 0보다 크면 공유자원 접근이 허용되며 S가 0이면 공유자원 접근 불가능.
- P, V는 원자적 실행이 보장되어야 함. 즉 synchronized 필요.

### 세마포어 유형
- S가 0과 1로만 이루어진 **이진 세마포어**
- S가 2 이상의 양수 값을 가진 **카운팅 세마포어**


- 카운팅 세마포어는 자원 pool을 사용할 때 유용하다. DB Connection 개수 제한, 파일 다운로드 동시 실행 제한 등.

### 뮤텍스와 세마포어
- 동작 방식
  - 뮤텍스는 상호 배제를 위한 동기화 기법.
  - 세마포어는 카운팅 기법, 툭정 개수의 스레드가 동시에 공유 자원에 접근할 수 있도록 제어함.
  - 이진 세마포어는 뮤텍스와 유사한 역할을 함.
- 소유권
  - 뮤텍스는 소유권이 있음. Lock
  - 세마포어는 소유권이 없음. 세마포어를 사용하는 스레드들이 모두 세마포어를 해제할 수 있다.
- 초기값
  - 뮤텍스는 기본적으로 잠겨져 있음.
  - 세마포어는 초기값 설정할 수 없음.
- 사용목적
  - 뮤텍스는 상호배체를 위해 사용됨.
  - 세마포어는 리소스의 한정적인 사용을 제어. 특정 개수의 스레드만 공유 자원에 동시에 접근 가능하도록 함. 

- 자바에서는 뮤텍스를 고도화한 모니터 객체와 세마포어 구현체를 제공하고 있다.
