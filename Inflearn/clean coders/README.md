## 강의 목차
1. 소개
    - 돌아가는 코드는 아무나 짤 수 있다. 읽을 수 있는 코드를 짜자.

    - 처음에 어떻게 개발할지 그리고 시작하자.
    - IDE를 활용해서 레거시 리팩토링하자.
    - TDD를 이용해서 새로운 기능을 개발하자.
        - 기존 코드에 새로운 기능 개발할 때, 기존 코드에는 TDD가 없는데 어떻게 TDD를 적용할 수 있을까.
    - OOP/SOLID 기반한 설계

2. Function
    - 함수는 한 가지 일만 해야한다.
3. Function Structure
    - CQS

    - Tell, Don't Ask
    - Law of Demeter
4. Forms(코드의 구조)
    - 올바르게 comments 사용하는 법

    - code formatting
    - class - 어떤 메서드를 제공하는 것이 좋을까
    - data structure : 왜 데이터가 아닌 '기능'으로 시작해야할까
5. TDD
    - 이론

    - 마틴 파울러- Bowling Game
    - 캔트백 - Tyrant
    - Name Inverter
    - Prime Number Generator

6. Architecture
    - 아키텍처의 정의
    - Web System의 아키텍처 - 어떻게 해야 변경을 최소화할 수 있을까.

7. SOLID
    - 5가치 원칙

    - 원칙을 적용한 시스템 설계

8. Next
    - Working Effectively with Legacy Code

## 강의 목표
이 강의를 통해 내가 배우고자 하는 것은 다음과 같다.

- 레거시 리팩토링 및 테스트

- 실무에서 내가 항상 고민하던 문제는 **테스트를 할 수 없어서 리팩토링을 하지 못하는 것**이다.

- 중복 코드 발생 -> 리팩토링하고 싶음. -> 테스트 할 수 없어서 리팩토링 불가 -> 계속 중복 코드 발생 -> 결국 악순환...

- 실무에서 이 문제를 해결하자.
