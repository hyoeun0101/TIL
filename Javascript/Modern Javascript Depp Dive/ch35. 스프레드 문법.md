- 스프레드 문법은 ES6에서 도입되었다.
## 스프레드 문법(...)
- 스프레드 문법 사용할 수 있는 대상 : for...of문으로 순회할 수 있는 이터러블 (Array, String, Map, Set, DOM 컬렉션, arguments)
- 하나로 뭉쳐있는 여러 값들의 집합을 개별적인 값들의 목록으로 변환한다.
- 스프레드 문법의 결과르 변수에 할당할 순 없다.

```javascript
// [1,2,3] -> 1 2 3 (개별 요소로 분리)
cosole.log(...[1,2,3]); // 1 2 3

console.log(...['Hello']); // H e l l o
```

## 35.1 함수 호출문에서 인수 목록에 사용
- 스프레드 문법이 제공되기 이전에는 Function.prototype.apply를 사용하였다.

```javascript
const arr = [1,2,3];

//Math.max는 가변 인자 함수
const max = Math.max(arr); //NaN, 인수에 배열 전달할 수 없음.

const max2 = Math.max.apply(null, arr);

const max3 = Math.max(...arr);
```
- `Rest 파라미터`와 혼동하기 쉬우기 주의할 것.
    - `Rest 파라미터`는 함수에 전달된 인수의 목록을 배열로 받기위해 함수 선언 시 파라미터에 사용
    - Rest 파라미터와 스프레드 문법은 반대 개념.

```javascript
function foo(...rest) { // 1 2 3을 [1,2,3]으로 변환
    console.log(rest); // [1,2,3] 출력!
}

foo(...[1,2,3]); // [1,2,3]을 1 2 3 으로 전달
```

## 35.2 배열 리터럴 내부에서 사용

### concat
- 배열 2개를 하나의 배열로 결합시킴.

```javascript
var arr = [1,2].concat([3,4]);

console.log(arr); // [1,2,3,4]

//스프레드 문법 사용
const arr2 = [...[1,2], ...[3,4]];
console.log(arr2); // [1,2,3,4]
```

### splice
- 배열 중간에 요소를 추가 또는 제거함.

```javascript
var arr1 = [1,4];
var arr2 = [2,3];

arr1.splice(1, 0, arr2);
console.log(arr1); //[1,[2,3],4]
```
```javascript
var arr1 = [1,4];
var arr2 = [2,3];

//스프레드 문법 사용
arr1.splice(1, 0, ...arr2);
console.log(arr1); // [1,2,3,4]
```

### 배열 복사

```javascript
var origin = [1,2];
var copy1 = origin.slice();

console.log(copy1); //[1,2]
console.log(origin === copy1) //false

//스프린트 문법 사용, 얕은 복사하여 복사본 생성
var copy2 = [...origin];

console.log(copy2); //[1,2]
console.log(origin === copy2) //false
```
