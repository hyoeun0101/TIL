## 🍎 Regex

```javascript
/regex?/i

/찾고자하는 패턴/옵션
```

### 그룹 및 범위

| Character | 뜻                           | 예시            | 예시 결과           |
| --------- | ---------------------------- | --------------- | ------------------- |
| `\|`      | 또는                         | `/Hi\|Hello/`   | Hi, Hello 문자 매치 |
| `()`      | 그룹                         | `/(Hi\|Hello)/` | 그룹 Hi, 그룹 Hello |
| `[]`      | 문자셋, 괄호안의 어떤 문자든 |
