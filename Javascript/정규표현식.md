## 🍎 패턴 문법

### Groups and ranges

| Character | 뜻                                     |예시|매칭되는 값|
| --------- | -------------------------------------- |-------|------|
| `\|`      | 또는                                   | `Hi\|Hello` |Hi, Hello|
| `()`      | 그룹                                   |`gr(a\|e)y` |gray, grey (해당 글자에는 group1이 지정됨)|
| `[]`      | 문자셋, 괄호안의 어떤 문자든 일치하면 ok          |gr[abcde]y 또는 gr[a-e]y|gray,grby,grcy,grdy, grey |
| `[^]`     | 부정 문자셋, 괄호안의 어떤 문가 아닐때 |
| `(?:)`    | 찾지만 기억하지는 않음                 |gr(?:a|e)y|gray, grey (해당 글자에 group이 지정되지 않음)|
### 많이 사용하는 패턴
- [a-zA-Z0-9] : 문자 + 숫자 
- [^a-zA-Z0-9] : 문자X 숫자 X 특수문자O
### Quantifiers

| Character   | 뜻                                  |예시|매칭되는 값|
| ----------- | ----------------------------------- |----|---------|
| `?`         | 없거나 있거나 (zero or one)         |gra?y|gray, gry|
| `*`         | 없거나 있거나 많거나 (zero or more) |gra*y|gry, gray, graaay|
| `+`         | 하나 또는 많이 (one or more)        |gra+y|gray, graaaay|
| `{n}`       | n번 반복                            |gra{2}y|graay|
| `{min,}`    | 최소                                |gr{2,}y| graay, graaay, graaaay|
| `{min,max}` | 최소, 그리고 최대                   |gr{2,3}y|graay, graaay|

### Boundary-type

| Character | 뜻               |예시|매칭되는 값|
| --------- | ---------------- |---|------------|
| `\b`      | 단어 경계        | ||
| `\B`      | 단어 경계가 아님 |
| `^`       | 문장의 시작      |
| `$`       | 문장의 끝        |

### Character classes

| Character | 뜻                           |예시|매칭되는 값|
| --------- | ---------------------------- |--|---------|
| `\`       | 특수 문자가 아닌 문자        |\.|.|
| `.`       | 모든 글자 (줄바꿈 문자 제외) |
| `\d`      | digit 숫자                   |
| `\D`      | digit 숫자 아님              |
| `\w`      | word 문자                    |문자+숫자
| `\W`      | word 문자 아님               |특수문자 + 공백
| `\s`      | space 공백                   |
| `\S`      | space 공백 아님              |



### 옵션 종류
- global : 매칭되는 여러 값을 기억함
- multiline : 여러 줄에서 문장의 끝
- case insensitive : 대소문자 구분하지 않음
