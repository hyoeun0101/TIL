- 컴퓨터는 CPU로 연산을 하고, 메모리를 통해 데이터를 기억한다. 메모리 셀 하나의 크기는 1Byte(8bit)이다. 컴퓨터는 1Byte 단위로 데이터를 읽거나 저장한다. 메모리에 저장되는 모든 값은 2진수로 저장된다.

## 🍎 변수 선언, 호이스팅
- 자바스크립트 엔진은 소스코드의 평과 과정을 거치고, 모든 선언문(변수, 함수 선언문)을 소스코드에서 찾아 먼저 실행한다. 
- 소스코드의 평가 과정 후, 선언문을 제어한 소스코드를 순차적으로 실행한다.
- 변수 선언문이 제일 위로 끌어 올려져 동작하는 것을 `호이스팅`이라고 한다.

- 변수 선언 : 런타임 전에 실행 
- 값 할당 : 런타임에 실행
- 상수 : 값을 변경할 수 없다.

## 🍎 데이터 타입
- 원시 타입 6개 : Number, String, Boolean, undefined, null, Symbol
  - 원시 타입은 immutable이다. (불변)
- 객체 타입 : 객체 타입은 mutable이다.

### Number
- 모든 수를 실수로 처리한다. 정수, 실수 따로 처리하지 하지 않는다.
```javascript
console.log(1 === 0.1) // true
```
- 다음 세가지로도 표현할 수 있다.
    - Infinity : `console.log(10 / 0);`
    - -Infinity : `console.log(-10 / 0);`
    - NaN : `console.log(1 * 'String');`

### undefined
- 변수가 undefined라면 `선언 이후 할당된 적이 없다`는 것을 의미한다. (var는 값 할당 전 undefined로 초기화되기 때문)
### null
- null은 Null, NULL과 다르다.
- 변수에 nulld을 할당하는 것은 변수가 값 참조를 더이상 하지 않겠다는 것이다.
### Symbol
 - ES6에서 추가된 타입.
   - 외부에 노출되지 않으며, 중복되지 않는 유일무이한, 변경되지 않는 값.(immutable)
   - 객체의 유일한 프로퍼티 키를 만들 때 사용한다.

## 🍎옵셔널 체이닝 연산자 ?.
- 좌항의 피연산자가 null이거나 undefined이면 undefined를 반환, 아미녀 우항의 프로퍼티 참조값
```javascript
var elem = null;
var value = elem?.value;
console.log(value); //undefined
```
```javascript
var str = '';
var length = str && str.length;
console.log(length); //''

var str = '';
var length = str?.length;//0
console.log(length); //
```

## 🍎 null 병합 연산자
- 변수값에 디폴트값 설정할 때 유용
- 좌항의 피연산자가 null이거나 undefined이면 우항의 피연산자 반환, 아니면 좌항의 피연산자 반환 
```javascript
var foo = null ?? 'defualt string';
console.log(foo); // 'defualt string'
```
