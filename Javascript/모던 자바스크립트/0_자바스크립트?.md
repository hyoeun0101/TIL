## 🍎 자바스크립트
- 인터프리터 언어이다. 프로그래밍 언어를 컴퓨터 언어로 변환하는 일은 컴파일러나 인터프리터가 한다.
- ES6(자바스크립트 표준 사항), 브라우저가 제공하는 Web API, DOM, XMLHttpRequest, fetch등을 아울러 자바스크립트라고 한다. 
- 클래스 기반 객체지향 언어가 아닌 프로토타입 기반의 객체지향 언어이다.
- 가비지 컬렉터 존재.
- https://kangax.github.io/compat-table/es6 에서 브라우저 지원 현황을 볼 수 있다.

## 🍎 인터프리터 언어 VS 컴파일러 언어
|인터프리터|컴파일러|
|--------|-----|
|런타임에 한 줄씩 바이트코드로 변환한 후 실행한다.|코드가 실행되기 전인 컴파일에 소스 코드를 한번에 머신 코드로 변환한 후 실행한다.|
|실행 파일을 생성하지 않는다.|실행 파일을 생성한다.|
|인터프리터는 한 줄씩 바이트코드로 변환하고 즉시 실행한다.|컴파일 단계와 실행 단계가 분리되어 있다.|

## 🍎 자바스크립트 실행 환경
- 모든 브라우저는 자바스크립트를 실행할 수 있는 자바스크립트 엔진을 내장하고 있다.
