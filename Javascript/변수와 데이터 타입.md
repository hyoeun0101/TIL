## 변수

: 하나의 값을 저장한 메모리 공간의 이름. 개발자는 메모리 주소를 알지 못해도 변수가 메모리 주소와 매핑되어있기 때문에 변수를 통해 메모리에 접근한다.

- 할당(assignment) : 변수에 값 저장하는 것
- 참조(reference) : 변수에 저장된 값을 읽는 것

## 변수 선언

### 🍎var

- function level scope : 코드 블럭 내에서 선언해도 함수 내에선 전역 변수다.
- 런타임 이전에 선언이 실행되고 즉시 undefined로 초기화
- 변수 중복 선언 가능 : 중복 선언했을 때 마지막에 할당된 값을 가진다.
- var는 호이스팅으로 인해 가독성을 떨어뜨리고, 의도치 않은 오류가 발생할 수 있다.

### 🍎let

- block level scope
- 변수 중복 선언 금지
- 런타임 이전에 선언만 실행되고, 런타임 시 초기화된다.
- Temporal Dead Zone이 발생한다. TDZ란 선언 시작 점부터 초기화 전까지 변수를 참조할 수 없는 구간을 말한다.
- 재할당이 가능한 변수는 let으로 선언하고, 최대한 스코프를 좁게 만들어라.
- 호이스팅을 하지만 안하는 것처럼 동작한다.

### 🍎const

- 상수 : 재할당 불가
- 선언 동시에 초기화 해야한다.
- block level scope
- 일반적으로 SNAKE_CASE로 표현한다.
- const 키워드로 선언한 변수에 객체를 할당한 경우, 변수의 참조값을 변경할 수 없는 것이지 객체의 값을 변경할 수 없다는 건 아니다.
- 객체는 재할당할 일이 드물기 때문에 되도록이면 const로 선언해라. 재할당할 일이 생기면 그때가서 let으로 변경하는 것도 좋은 방법.
- 호이스팅을 하지만 안하는 것처럼 동작한다.

## 호이스팅

자바스크립트 엔진의 실행은 크게 두 가지로 나뉜다.

1. 소스코드 평가
2. 소스코드 실행  
   인터프리터가 소스코드를 실행하는 단계인 런타임 단계 이전에 소스코드 평가 단계를 거친다.  
   소스코드 평가 단계에서는 변수 선언을 포함한 모든 식별자의 선언을 먼저 실행한다.  
   따라서 코드의 위치에 상관없이 **변수가 코드의 제일 상단으로 끌어올려진 것처럼 동작** 하는데 이 특징을 `호이스팅`이라고 한다.

```javascript
console.log(id); //undefined
var id;
id = "khe";
//var id='khe'
console.log(id); //khe
```

:`변수 선언`은 런타임 이전에 실행되고 `값 할당`은 런타임 시에 이루어진다.

## 데이터 타입 7개

1. Number : immutable value
   - 실수로 처리
   - NaN : 숫자와 문자열 연산할 때
   - Infinity
   - -Infinity
2. String : immutable value
   - 템플릿 리터럴 : 백틱(``)으로 묶으면 줄바꿈 처리되고 ${}으로 표현식 삽입 가능
     - ex) console.log(`My name is ${name}`);
3. Boolean
4. undefined
   - 변수가 undefined라면 `선언 이후 할당된 적이 없다`는 것을 의미한다. (var는 값 할당 전 undefined로 초기화되기 때문)
5. null
   - `값이 없다.`라는 뜻
6. Symbol
   - ES6에서 추가된 타입.
   - 외부에 노출되지 않으며, 중복되지 않는 유일무이한, 변경되지 않는 값.
   - 객체의 유일한 프로퍼티 키를 만들 때 사용한다.
7. Object

**🍏 데이터 타입 왜 필요한가?**

- 값을 저장할 때 할당할 메모리 크기를 결정하기 위해
- 값을 참조할 때 한번에 읽어들여야 할 메모리 크기를 결정하기 위해
- 메모리에서 읽어들인 2진수를 어떻게 해석할지 결정하기 위해
