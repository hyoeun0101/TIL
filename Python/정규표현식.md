# 메타문자 기초

a와b사이 \n 제외한 모든 문자
|메타문자|설명|예시|예시|
|-----|------|----|----|
|Dot(.)|a와 b사이 \n을 제외한 모든 문자| a.b| aab, a0b|
|\*|0부터 무한(2억)까지 반복|ca\*t|caaat, ct|
|+|1부터 무한까지 반복|ca+t|cat, caaat|
|{m}| m번만 반복|ca{2}t|caat|
|{m,n}|m부터 n번까지 반복|ca{2,5}t|caat,caaaat|
|?|{0,1}과 같음.0번 또는 1번|ab?c|ac,abc|

# 자주 사용하는 문자 클래스

|\d| [0-9] : 숫자|
|\D|[^0-9] : 숫자가 아닌 것|
|\s|[\t\n\r\f\v] : 스페이스 공백(whitespace)|
|\S|[^\t\n\r\f\v] : 스페이스 공백 아닌 것|
|\w|[a-zA-Z0-9_] : 문자+ 숫자|
|\W|[^a-za-z0-9_] : 문자,숫자 아닌 것. 특수문자(\_는 제외),공백|

# 메타문자

| 메타문자 | 설명                                            | 예시                                                  | 결과                                            |
| -------- | ----------------------------------------------- | ----------------------------------------------------- | ----------------------------------------------- | -------------------------------------------- |
| \|       | or (또는)                                       | re.match('Crow                                        | Servo', 'CrowHello')                            | <re.Match object; span=(0, 4), match='Crow'> |
| ^        | 문자열의 맨 처음과 일치                         | re.search('^Life', 'Life is too short')               | <re.Match object; span=(0, 4), match='Life'>    |
| $        | 문자열의 맨 끝과 일치                           | re.search('short$', 'Life is too short')              | <re.Match object; span=(12, 17), match='short'> |
| \A       | ^ 와 같음. 문자열 처음과 매치.                  | re.MULTILINE 옵션이 먹히지 않음.                      |
| \Z       | $와 같음. 문자열 끝과 매치.                     | re.MULTILINE 옵션이 먹히지 않음.                      |
| \b       | 단어 구분자. 보통 whitespace에 의해 구분된다    | re.seatch(r'\bclass\b')                               | <re.Match object; span=(3, 8), match='class'>   |
| \B       | \b와 반대. whitespace로 구분되지 않은 단어 매치 | re.search(r'\Bclass\B', 'the declassified algorithm') | <re.Match object; span=(6, 11), match='class'>  |

# re모듈 사용하기

```
import re
p = re.compile('정규식')
m = p.match('매치시킬 문자열')

m = re.match('정규식', '문자열')
```

| method('정규식', '매치시킬 문자열') | 설명                                       | 결과값                            |
| ----------------------------------- | ------------------------------------------ | --------------------------------- |
| match())                            | 문자열 처음부터 정규식과 매치(통으로 매치) | 매치 성공 : match객체, 실패: None |
| search()                            | 문자열 전체에서 정규식과 매치              | 성공 : match 객체, 실패: None     |
| findall()                           | 정규식과 매치하는 문자열을 리스트로 리턴   | 성공 : ['s','d','d'], 실패: []    |
| finditer()                          | 매치하는 문자열을 iter객체로               | 성공,실패: iter객체               |

### match 객체의 메소드

| match객체 메소드 | 설명                                   |
| ---------------- | -------------------------------------- |
| group()          | 매치된 문자열 반환                     |
| start()          | 매치된 문자열 시작 위치 반환           |
| end()            | 매치된 문자열 끝 위치의 다음 위치 반환 |

# 컴파일 옵션

### 1. DOTALL

- DOT(.)에서 \n 문자만 제외라 했는데 \n 문자도 포함시킬 때 DOTALL 사용

```
import re
p = re.compile('a.b', re.DOTALL)
m = p.match('a\nb')
print(m)

>>  <re.Match object; span=(0, 3), match='a\nb'>
```

### 2. IGNORECASE ,I

- 대소문자 구별 없이 매치할 때

```
import re

p = re.compile('[a-z]+', re.I)
m = p.match('pyTHON')
print(m)
>>  <re.Match object; span=(0, 6), match='pyTHON'>
```

### 3. MULTILINE, M

- 예시로 알아보자
- ^ : 문자열의 처음
- & : 문자열의 끝

```
import re
p = re.compile("^python\s\w+")

data = """python one
life is too short
python two
you need python
python three"""

print(p.findall(data))
>>>['python one']
```

- data 전체에서 python으로 시작하는 문자열 매치.

```
import re
p = re.compile("^python\s\w+", re.MULTILINE)

data = """python one
life is too short
python two
you need python
python three"""

print(p.findall(data))
>>>['python one', 'python two', 'python three']
```

- 멀티라인 옵션 쓰면, 각 줄마다 매치한다.
