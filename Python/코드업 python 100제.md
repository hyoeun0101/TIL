### 10진수-> 16진수
```
a= 45
print("%x" %a)
print("%X" %a) # 대문자로 표현
```
### 10진수-> 8진수
```
print('%o' %a)
```
### 영어(문자)-> 10진수 : 아스키코드
```
print(ord('A'))
>>65
```
### 10진수-> 영어(문자)
```
print(chr(65))
>>A
```
### 소숫점 반올림
```
a= 3.45675
print(f'{a:.2f}') #2자릿수까지 출력
print('{:.2f}'.format(a))
print(format(a,".2f"))
```
