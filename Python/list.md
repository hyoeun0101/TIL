## 리스트 원소 추가
### 1. append(원소)
```
a = [1,2,3] 
a.append(4)
>>> [1,2,3,4]
```
### 2. insert(index, 원소)
```
a = [1,2,3]
a.insert(1,7)
>>> [1,7,2,3]
```
### + 연산자
```
a = [1,2,3]
a += [8,9]
>>> [1,2,3,8,9]
```
### extend(추가할 리스트)
```
a=[1,2,3]
a.extend([4,5,6])
>>> [1,2,3,4,5,6]
```
## 리스트 원소 삭제
### 1. del 리스트[index]
```
a = [1,2,3,4,5,6]
del a[2]
>>> [1,2,4,5,6]
```
### 2. remove(원소)
```
a = [1,2,3,4,5]
a.remove(3)
>>> [1,2,4,5]
```
- 삭제하고자 하는 원소 없을 경우 ValueError 발생.
- del a[a.index(3)] 이랑 같다.
