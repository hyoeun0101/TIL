# 1. 운영체제의 정의

### 운영체제란? operating system
- 컴퓨터의 하드웨어의 바로 윗단에 설치되는 소프트웨어   
    
`컴퓨터의 하드웨어` + `운영체제` => 진정한 컴퓨터 시스템   
각종 소프트웨어들은 이 컴퓨터 시스템에서 실행되는 것!   
   
### `커널(kernel)`?
- 컴퓨터 전원을 키면 운영체제 중 필요한 부분만 메모리에 올라가는데, 이 메모리에 상주하는 운영체제의 부분을 커널이라고 한다.
- 좁은 의미의 운영체제. 운영체제 코드 중에서도 핵심!   

# 2. 운영체제의 기능

- 하드웨어를 위한 역할 - 컴퓨터 시스템 내의 자원을 효율적으로 관리하는 것.
    - CPU,메모리,하드디스크 등 하드웨어 + 소프트웨어 자원을 통틀어 효율적으로 관리해서 좋은 성능을 내도록한다.

- 사용자를 위한 역할 - 컴퓨터 시스템을 편리하게 사용할 수 있는 환경을 제공하는 것.

- 보안의 역할 - 사용자와 운영체제 자신을 보호. 

# 3. 운영체제의 분류

__동시 작업을 지원하는가__
- 단일 작업(single tasking) 운영체제 : 한 번에 하나의 프로그램만 실행시킬 수 있는 운영체제. (초창기 운영체제 ex)DOS)
- 다중 작업(multi tasking) 운영체제: 다양한 프로그램을 서로 다른 창에 동시에 띄울 수 있는 운영체제.

운영체제가 `다중작업`을 처리할 때 여러 프로그램이 CPU와 메모리를 동시에 공유를 한다.    
이와 같이 CPU의 작업 시간을 여러 프로그램들이 나눠서 쓰는 걸 `시분할 시스템(time sharing system)`이라고 한다.   
메모리 공간을 분할해서 여러 프로그램을 메모리에 올려놓고 처리하는 걸 `다중 프로그래밍 시스템`이라고 한다.   
사용자 관점에서 볼 때는 입력의 결과를 바로 화면에 보여주기 때문에 `대화형 시스템(interactive system)`이라고도 한다.   

__다중 사용자에 대한 동시 지원하는가__
- 단일 사용자용 운영체제 : 한 번에 한 명의 사용자만 사용 가능한 운영체제
- 다중 사용자용 운영체제 : 여러 사용자가 동시에 사용 가능한 운영체제 ex) 메일 서버,웹서버

__작업을 처리하는 방식__
- 일괄처리 방식: 요청된 작업을 모아 일정량이 쌓이면, 일괄적으로 처리. 모든 작업이 완전히 종료된 후 응답하므로 응답시간이 길다. 
- 시분할 방식 : 작업을 처리할 때 컴퓨터의 처리 능력을 시간 단위로 분할해서 사용하는 방식. ex) 대화형 시스템 (사용자의 요청에 대한 응답을 바로 얻을 수 있음.)
- 실시간 운영체제 : 정해진 시간 안에 어떠한 일이 반드시 처리되어야함.
    - hard realtime system : 주어진 시간을 지키지 않으면 안됨. ex) 로켓, 원자로 제어 시스템
    - soft realtime system : 정해진 시간을 지켜야 올바른 기능 수행 가능 ex) 멀티미디어 스트리밍 시스템

CPU를 관리하는 방법
어떠한 프로세스에 CPU를 할당해 작업을 처리할 것 인가. -> CPU 스케줄링 : CPU를 가장 효율적으로 사용하면서, 특정 프로세스가 불이익을 당하지 않도록!
- 선입선출 (FCFS) : 먼저 온 프로세스를 먼저 처리.
    - 앞의 프로세스가 끝날 때까지 계속 기다려야하기 때문에 비효율적.
    - 앞에 긴 작업을 가진 프로세스가 있으면 뒤에 짧은 작업을 가진 프로세스는 계속 기다려야함.
- 라운드 로빈 : CPU를 할당받으면 사용할 수 있는 시간을 제한.
    - 정해진 시간이 지나면 CPU를 내어놓고 맨뒤로 가서 대기
    - 할당시간을 얼마로?
- 우선순위 : 프로세스에 우선순위를 부여하고, 우선순위 높은 순으로 CPU를 할당
    - 오래 대기하는 프로세스를 방지하기 위해 오래 대기하면 우선순위를 높여주는 방식으로 활용.
