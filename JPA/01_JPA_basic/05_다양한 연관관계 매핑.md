## 🍎 일대다 - @OneToMany
[일대다 단방향] - 권장X
- 일대다에서 일이 연관관계 주인.

```java
@Entity
public class Team {
    @Id @GeneratedValue
    @Column(name = "TEAM_ID")
    private Long id;

    @Column(name = "TEAM_NAME")
    private String name;

    @OneToMany
    @JoinColumn(name = "TEAM_ID")
    private List<Member> members =  new ArrayList<>();
}
```
