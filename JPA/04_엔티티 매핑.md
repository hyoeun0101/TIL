## 🍎 객체-테이블 매핑
### @Entity
- name 속성 : JPA의 엔티티 이름을 지정한다. 기본값은 클래스 이름 그대로 사용. 
### @Table
- 엔티티와 매핑할 테이블 지정
- name 속성 : 매핑할 테이블 이름. 기본값은 엔티티 이름 사용
- catalog 속성: 데이터베이스 catalog 매핑
- schema 속성 : 데이터베이스 schema 매핑
- uniqeConstrains 속성 : DDL 생성 시 유니크 제약 조건 생성
