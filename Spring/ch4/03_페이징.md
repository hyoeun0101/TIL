# 페이징

```java
public class PageHandler{
    int totalCnt;//총 게시물 수
    int pageSize;//한 페이지의 크기
    int naviSize;//네비게이션의 크기
    int totalPage;//전체 페이지 갯수
    int page;//현재 페이지
    int beginpage;//네비게이션의 시작 페이지
    int endPage;//네비게이션의 마지막 페이지
    boolean showPrev;//이전 페이지로 이동 가능 여부
    boolean showNext;//다음 페이지로 이동 가능 여
}
```

### LIMIT[offset,] row_count
offset : 맨 처음부터 몇 개 떨어져있냐
rowCount: 게시물 몇 개 가져올거냐.

- offset 이해하기
|page|offset|게시물 번호|
|----|------|----------|
|1|0|1~10|
|2|10|11~20|
|3|20|21~30|
|4|30|31~40|
    - offset = (page-1) * 10
