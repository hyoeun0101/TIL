### 스프링 부트 핵심 기능 5가지

- WAS : 톰캣 같은 웹 서버 내장, 별도의 웹 서버 설치 X
- 라이브러리 관리 : 버전 자동으로 관리, 손쉬운 빌드 구성을 위한 스타터 종속성 제공(웹 프로젝트면 웹과 관련 라이브러리 알아서 땡겨옴)
- 자동 구성 : 프로젝트 시작에 필요한 스프링과 외부 라이브러리의 빈을 자동 등록
- 외부 설정 : 환경에 따라 달라져야 하는 외부 설정 공통화
- 프로덕션 준비 : 모니터링을 위한 메트릭, 상태 확인 기능 제공
