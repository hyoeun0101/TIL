## Maven
```xml
<dependencies>
    <dependency>
        <groupId>junit</groupId>
        <artifactId>junit</artifactId>
        <version>4.7</version>
        <scope>test</scope>
    </dependency>
</dependencies>


```
### 의존성 scope
- complie : scope 지정하지 않은 경우 기본값. 프로젝트의 컴파일, 테스트, 런타임(실행)에 해당 의존성을 사용한다.
- provided : JDK 또는 컨테이너가 해당 라이브러리를 제공할 때 사용한다. ex) JSP, Servlet API
- runtime : 컴파일 시에는 사용하지 않으나, 런타임과 테스트 시에 해당 의존성을 사용한다. ex) JDBC 드라이버
- test : 테스트의 컴파일, 런타임 시에 사용한다. ex) easymock, junit
- system : provided와 비슷하지만 사용자가 jar 파일의 위치를 지정한다는 점이 다르다. system 의존성을 사용하려면 <systemPath></systemPath> 를 이용하여 jar 파일의 위치를 지정해야 한다. 예를 들면 ${user.home}/test-1.0.jar


### <optional> 지정
```xml
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <optional>true</optional>
<!--            optional 설정: 다른 프로젝트에서 이 프로젝트를 의존할 때, lombok은 의존하지 않음. -->
</dependency>
```
- <optional>true</optional>을 작성하면 다른 프로젝트에서 이 프로젝트를 의존할 때 해당 의존성은 사용하지 않는다.
