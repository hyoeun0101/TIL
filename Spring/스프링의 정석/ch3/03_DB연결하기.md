## 🍎 스프링에서 DB 연결하기

### 필요한 라이브러리

- mysql connector j
- spring jdbc
- spring test

### 순수 자바 소스로만 연결하기

```java
package com.hyocoding.ch1;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.ResultSet;
import java.sql.Statement;

public class DBConnectionTest {
	public static void main(String[] args) throws Exception{

		 	String DB_URL = "jdbc:mysql://localhost:3306/springbasic?useUnicode=true&characterEncoding=utf8";

	        // DB의 userid와 pwd를 알맞게 변경해야 함
	        String DB_USER = "eun";
	        String DB_PASSWORD = "1234";
			//1. DriverManager로 DB의 커넥션 얻기
	        Connection conn = DriverManager.getConnection(DB_URL, DB_USER, DB_PASSWORD);
	        Statement stmt  = conn.createStatement(); // Statement를 생성

	        String query = "SELECT now()";
	        ResultSet rs = stmt.executeQuery(query); // 쿼리문 실행 결과를 ResultSet에 담는다.

	        while (rs.next()) {
				//첫번 째 컬럼의 값 읽기
	            String curDate = rs.getString(1);
	            System.out.println(curDate);       // 2022-01-11 13:53:00.0
	        }
	}
}
```

### DataSource 빈 등록하기.

- DataSource는 DB의 커넥션을 얻기 위한 객체이다.
- 빈으로 등록한 후 DB 커넥션이 필요한 곳에 주입하여 DB 커넥션을 얻을 수 있다.

1. 빈 등록하기
   [root-servlet.xml]

```xml
<!-- Root Context: defines shared resources visible to all other web components -->
	<bean id="dataSource" class="org.springframework.jdbc.datasource.DriverManagerDataSource">
		<property name="driverClassName" value="com.mysql.jdbc.Driver"></property>
		<property name="url" value="jdbc:mysql://localhost:3306/springbasic?useUnicode=true&amp;characterEncoding=utf8"></property>
		<property name="username" value="asdf"></property>
		<property name="password" value="1234"></property>
	</bean>
```

2. 주입받기

```java
@RunWith(SpringJUnit4ClassRunner.class)
@ContextConfiguration(locations={"file:src/main/webapp/WEB-INF/spring/**/root-context.xml"})
public class DBConnectionTest3 {
    @Autowired
    DataSource ds;

    @Test
    public void springJdbcTest() throws Exception{
        Connection conn=ds.getConnection();//DB 커넥션 획득
        System.out.println("conn="+conn);
        assertTrue(conn!=null);
    }
}
```
