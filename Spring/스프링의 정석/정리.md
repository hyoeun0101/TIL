### 🍎 바이너리 데이터, 텍스트 데이터

- 바이너리 : 문자+숫자로 이루어진 데이터
  - HTTP로 바이너리 파일을 주고 받을 때 HTTP는 텍스트 기반 프로토콜이기 때문에 쓸 때 숫자를 문자로 변경, 읽을 때 문자를 숫자로 변경하는 작업이 필요하다.
  - ex> 12(int, 4byte) -> '1','2' (char, 2byte)
- 텍스트 : 문자로 이루어진 데이터 (메모장으로 열면 알아볼 수 있음)

---

### 🍎 MIME

- 텍스트 기반 프로토콜에 바이너리 데이터 전송하기 위해 고안. HTTP의 Content-Type헤더에 사용하여 데이터의 타입을 명시한다.
- text/html, text/plain, text/css, text/javascript
- image/webp, image/bmp
- audio/midi, audio/ogg 등
- video/webm, video/ogg
- application/json등 - 모든 종류의 이진 데이터

### 🍎 Base64

- 바이너리 데이터를 안전하게 전송하기 위해 사용한다.
- 'a'~'z', 'A'~'Z', '0'~'9', '+', '/' 총 64개의 문자로 구성
- 바이너리 데이터를 텍스트 데이터로 변환한다.

### 정리

- 바이너리 데이터를 HTTP로 전송하기 위한 두 가지 방법이 있다.
- MIME으로 HTTP 헤더에 타입 명시하기.
- Base64로 바이너리 데이터를 텍스트로 인코딩하여 전송하기.

## 🍎 XML의 특수 문자 처리

특수 문자 <, >,& 는 변환 필요.

ex)

```xml
<update id="update" parameterType="BoardDto">
    UPDATE board
    SET title = #{title},
        content = #{content},
        up_date = now()
    WHERE bno = #{bno} and bno <> 0
</update>
```

1. 변환하기 <> -> `&lt; &gt;`
2. `<![CDATA[ 여기 내용 ]]>` 으로 감싸기
   - 여기 내용에는 XML 태그가 없다는 뜻.

## 🍎 MyBatis #{} ${} 태그 차이

1. #{}
   - PreparedStatement를 사용한다.
   - #{}태그는 ?로 바뀌며 문자열일경우 자동으로 따옴표를 붙여준다.
   - 값에만 사용할 수 있어 SQL Injection 방지할 수 있다.

```sql
SELECT CUST_ID
FROM S_CUSTOMER
WHERE CUST_ID = #{custId}
```

```java
String sql = "INSERT INTO board VALUES (?,?,?)";
PreparedStatement pstmt = conn.prepareStatement(sql);
int result = pstmt.executeUpdate();
```

2. ${}
   - Statement를 사용한다.
   - 값을 사용하려면 따옴표를 붙여야 한다.
   - SQL Injection을 예방할 수 없다. 그래서 값을 전달할 때는 사용하지 않는 것이 좋다.
   - 테이블이나 컬럼명을 전달하고 싶을 때 사용한다.

```sql
SELECT CUST_ID
FROM ${TABLE_NAME}
```

```java
String sql = "INSERT INTO board VALUES ('"+title+"')";
Statement stmt = conn.createStatement();
int result = stmt.executeUpdate(sql);
```
