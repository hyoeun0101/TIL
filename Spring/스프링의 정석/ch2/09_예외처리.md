## 🍎 스프링에서 예외처리하는 법

1.  try-catch 문 사용

2.  컨트롤러의 `@ExceptionHandler` 붙인 메서드로 처리

3.  `@ControllerAdvice` 붙인 클래스의 `@ExceptionHandler` 메서드로 처리

4.  예외 종류별로 뷰 지정하기

5.  statuscode별로 뷰 지정하기

## 🍎 @ExceptionHandler

- 예외처리를 위한 메서드에 @ExceptionHandler를 붙인다.

```java
@Controller
public class ExceptionController{
    //처리할 예외가 여러 개면 배열로 작성.
    //@ExceptionHandler({NullPointerException.class, FileNotFoundException.class})
    @ExceptionHandler(Exception.class)
    public String catcher(Exception ex, Model m){
        m.addAttribute("ex",ex);
        return "error";
    }

    @RequestMapping("/ex")
    public String main(Model m)throws Exception{
        m.addAttribute("msg","message for ExceptionController.main()");
        //예외 발생
        throw new Exception("예외 발생");
    }
}

```

- **주의** : catcher의 모델과 main의 모델은 서로 다른 객체이다.

## 🍎 @ControllerAdvice

- 전역 예외 처리 클래스에 붙이기
- `@ControllerAdvice("com.hyocoding.ch1")` 지정된 패키지의 하위에서 발생한 예외만 처리한다.

## 🍎 예외 종류별 페이지 처리하기

1. servlet-context.xml 에 등록

```xml
<beans:bean class="org.springframework.web.servlet.handler.SimpleMappingExceptionResolver">
    <beans:property name="defaultErrorView" value="error"/>
    <beans:property name="exceptionMappings">
        <beans:props>
            <beans:prop key="com.hyocoding.ch1.MyException">error400</beans:prop>
        </beans:props>
    </beans:property>
    <beans:property name="statusCodes">
        <beans:props>
            <beans:prop key="error400">404</beans:prop>
        </beans:props>
    </beans:property>
</beans:bean>
```

- MyException이 발생하면 statusCode는 404로 처리된다.
- `WEB_INF/views/error400.jsp` 가 화면에 띄워진다.

## 🍎 statuscode별 페이지 처리하기

1. web.xml에 추가

```xml
<error-page>
    <error-code>400</error-code>
    <location>/error400.jsp</location>
</error-page>

<error-page>
    <error-code>500</error-code>
    <location>/error500.jsp</location>
</error-page>
```

2. WEB-INF에 jsp추가
   [error400.jsp]

```xml
<%@ page isErrorPage="true" %>
[400] 잘못된 요청입니다.
```

## @ResponseStatus

: 응답 메세지의 상태 코드 변경하기.

- BAD_REQUEST 는 400
- INTERAL_SERVER_ERROR 는 500 으로 바꿔준다.

```java
@ExceptionHandler(Exception.class)
@ResponseStatus(HttpStatus.BAD_REQUEST)
public String catcher3() {
    System.out.println("===========Global Catcher3===========");
    return "error";
}
```

## 🍎 예외 처리 과정

클라이언트 요청 -> DispatcherServlet -> Controller (! 예외발생 !) -> DispatcherServlet -> `HandlerExceptionResolver`

`HandlerExceptionResolver` 에선 다음의 우선순위로 예외를 처리한다.

1. ExceptionHandlerExceptionResolver
2. ResponseStatusExceptionResolver
3. DefaultHandlerExceptionResolver

- 파일 찾아보기
  - maven > spring-webmvc > org.springframework.web.servlet > DispatcherServlet.properties

## JSP에서 예외 출력하기

```xml
<h1>발생한 예외: ${ex}</h1>
<h1>예외 메세지 : ${ex.message}</h1>
<c:forEach items="${ex.stackTrace}" var="i">
	<li>${i.toString()}</li>
</c:forEach>
```

- <%@ page isErrorPage=true %>를 작성하면 ex를 모델에 추가하지 않아도 된다.
- isErrorPage=true이면 statusCode는 디폴트로 500이다.

```xml
<%@ page isErrorPage="true" %>
<h1>발생한 예외: ${pageContext.exception}</h1>
<h1>예외 메세지 : ${pageContext.exception.message}</h1>
<c:forEach items="${pageContext.exception.stackTrace}" var="i">
	<li>${i.toString()}</li>
</c:forEach>
```
