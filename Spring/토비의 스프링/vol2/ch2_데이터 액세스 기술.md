## 정리

- DAO 패턴을 통해 데이터 액세스 계층을 분리할 수 있다.
- 스프링 JDBC는 DAO를 템플릿/콜백 방식을 통해 편리하게 작성할 수 있게 해준다.
- SQL 매핑 기술인 iBatis도 템플릿/콜백 패턴을 가진다.
- JPA, 하이버네이트는 템플릿/콜백과 자체 API를 선택적으로 사용한다.
- 트랜잭션 경계설정은 xml과 애노테이션을 통해 정의할 수 있다. 또한 트랜잭션 AOP를 적용할 때, 프록시나 AspectJ를 사용한다.
- 스프링은 여러 데이터 액세스 기술로 만든 DAO를 같은 트랜잭션 안에서 동작하도록 한다. 하나 이상의 DB를 사용할 때는 JTA 기능을 활용해야 한다.
